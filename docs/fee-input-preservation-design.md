# 费用输入错误与文件选择保全

2026-11-04，第124轮，本地候选。目标是修复上一轮确认的三个边界：无效费用进入整页恢复、同项目重绘丢失未交接文件选择、折叠面板反向Tab停在首项。其他六项模态故障仍后置，不将本轮称为完整移动端加固。

## 数值错误保持在费用字段

[费用计价](../src/engine/pricing.ts)在原`requireNumeric`入口校验解析和有限性。缺失输入继续使用`PRICING_INPUT_MISSING`；格式错误或NaN/Infinity使用新增的`PRICING_INPUT_INVALID`，带费用ID、计费方式和字段。固定/实际金额、数量与单价、比率与解析基数、天数和阶梯参数共用这一边界，档位上界在排序比较前检查。

只把Decimal解析器明确的输入拒绝归为字段错误；解析基数回调等意外异常继续由运行时边界处理。原文不改、不补零，不把库错误吞掉后继续算。没有改变通用d/q、有效数字、舍入、比率定义、负数业务规则、税务或Incoterms费用归属。有效有限输入保留原有支持的格式；本轮不声称任意极端运算结果均不会溢出。

原界面已有费用定位与输入核对入口。无效费用`-e`现在显示费用错误，保留模型和输入原文；可定位原金额字段，修正为有效文本后重算，不再进入整页恢复。

## 原File对象由明确的读取方接管

[文件节点保全](../src/ui/file-input-retention.ts)在同项目重绘时保留尚未交接的原文件输入节点，保持File对象身份；不复制File、不序列化它，也不向input.value写伪造路径。模板安装前检查唯一ID、文件类型与属性是否匹配；缺失、重复或不兼容目标拒绝替换，原选择保留。安装前抛错的回滚亦用真实DOM验证，不把它扩展成任意外部修改后的通用事务保证。

主工作台按既有项目对象身份区分同项目与明确替换；项目替换使用新输入，不继承旧文件选择。成分附件、精度和封套的局部刷新也使用同一函数，避免全局保全后又被局部刷新覆盖。

原文件change入口通过`takeSelectedFile`取得File，再明确清空控件并交给既有读取流程。WeakMap只记录已接管FileList的身份，随输入节点回收，不缓存业务JSON或宣称文件已保存。一个新FileList再次选择同一File，仍视为未交接选择。原读取代次、取消、失败和迟到拒绝规则继续由原控制器负责。

上一轮的保全测试未派发解析事件，不能据此认定普通导入丢失资料；本轮分别检查未交接选择和已接管读取，并重新运行包含真实文件导入、失败与迟到流程的原46套浏览器回归。

## 折叠状态键盘导航

[移动面板](../src/ui/mobile-settings.ts)保留原生dialog和既有返回逻辑，Tab边界排除负tabIndex、hidden/inert、不可见控件，以及关闭details内部不属于可见summary的控件。实际折叠状态下Shift+Tab从首项移动至可聚焦末项；展开后原有双向循环继续检查。

## 当前验证与历史记录各自绑定

6240项单测、原生表单验证、新运行文件及重跑的46套流程各自保留实测时的真实源码指纹。财务回归完成后，仅IO测试桩与九份校验元数据变化；实际执行的生产代码、浏览器驱动和运行文件逐项相同，原财务观察指纹不改写。38份历史报告保持（含本轮三份工程未通过记录）原文，旧运行字节只从不可变历史报告核对，不再要求新HTML冒充旧产物。新运行文件有独立清单与完整浏览器记录；历史通过不能替代本轮验收。
