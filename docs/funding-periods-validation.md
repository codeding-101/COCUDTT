## API 与计算边界

- `src/domain/funding-periods.ts`：期间表、明确期间舍入假设与独立审计类型；默认状态待确认、空依据、边界false，不加入旧FundingAssumption。
- `src/domain/funding-periods-validation.ts`：运行时结构检查。允许未完成草稿，拒绝错误选项、非文本/超4000字符、非布尔确认、超100期、空/重复/保留ID；业务就绪另查。
- `src/engine/funding-periods.ts`：`calculateFundingPeriods(result, schedule, rounding)`接收现有资金计算产生的原始结果及两个独立输入，返回独立期间审计。明确不应用返回null，不表示零利息；即使不应用，输入结构仍检查。

现有FundingResult保留原始未舍入字段；即使含旧1.4舍入审计，新函数也不读取其舍入金额、原成本显示字符串或片段成本作输入。调用方先完成原资金/报价绑定校验；归集函数另核对主体、币种、年基数、日期/天数及原计算分段的顺序和完整覆盖。此API不接受付款JSON或未知业务文件。

期间表必须明确提供且独立确认，整体/各期及舍入依据均非空。首尾及相邻期严格覆盖整个原期间，不重排、补期或修补分段。零天数只能使用明确空表，不能造零长度期间。起日包含、止日不包含，截止日的本金/新率事件由原算法审计，不生成额外归集日。

各片段由原本金、实际年利率、年基数及交集的整数天数重建精确BigInt分数；先按期求和再按明确步长舍入一次，合计不再舍入、不补尾差、不资本化。没有按已展示成本作比例分摊。每期原分数之和与全部原分段精确分数比较，避免漏日或重复计入。金额不转JS Number；日期交集使用UTC民用日整数，计算不逐日迭代。

## 独立审计与输入隔离

审计记录整体/各期依据、确认、币种、方式和规范化步长；原值、按期舍入合计、合计后舍入、两者差额、调整及精确分数分别列明。每期保留原段零起算索引、交集、天数、本金、实际年利率及对应依据。段索引只对应本次原结果快照，不是永久业务ID；本金依据链包含期初假设与截至该段的本金事件，利率依据取该段生效来源。

原值及调整的循环小数最多256有效位展示，精确分数另存。HALF_UP/HALF_EVEN/DOWN及任意正十进制步长沿用明确数学含义，不从币种推定。差额可以为负；零调整保留0/1，不产生负零。

冻结原结果、期间与舍入输入后仍可计算。审计的数组独立创建，期间只复制明确字段，不将未知嵌套扩展带入可变审计。函数不改原分段数量、原资金成本、原舍入、期末本金/利率、付款或项目数据；内部审计目前仅通过API提供，不能宣称界面或Excel已支持新期间。
