# 受限组件会话的启动与关闭

2026-11-03，第122轮，本地诊断候选。

范围是一份受信子文档里的现有字段帮助和首次引导，不是完整工作台。原组件及其限定适配不变；会话只协调两个明确工厂、启动任务、私有就绪身份与关闭顺序，不取得财务、源文件保存或客户确认权限。

启动依次加载字段帮助、创建帮助、加载引导、创建引导。状态分别记录模块等待与工厂等待。取消只停止后续准备；已经创建的组件与原文保留，可以继续操作，核对后再释放登记资源。当前实现不尝试中断模块请求：原Promise未结束时仍显示等待，不允许准备关闭确认。迟到模块不继续创建下一组件；已启动工厂迟到交回的句柄则必须登记保留，不能丢弃。

模块失败保留先前组件。工厂返回可检查的部分准备句柄时，保留DOM与已登记资源供明确关闭；工厂抛错或没有返回有效句柄时，无法证明是否留下资源，记录未知状态并保留引导保护，不宣称完整关闭。该未知边界目前只验证拒绝，不提供自动消除未知的能力。

就绪和关闭身份都是实例私有对象。关闭选择绑定当前两个组件、引导资源、原文和代次；复制、跨实例、取消、观察到的输入往返和结构ABA都使旧身份失效。检查回调发生重入或改变代次时不覆盖较新的状态。每次只保留一份就绪和一份关闭核对，不建立无限历史或业务缓存。确认只授权释放资源，不认证资料已保存或原文被冻结。

引导租约登记五项资源：子文档localStorage保护、document input/change、window pagehide及MutationObserver。只在验证过的受信子文档安装，原页面的存储属性与回调不包装。存储保护捕获原描述符而不读取其值；所有已知组件关闭且物理任务结束后，才退役引导资源并恢复原描述符。遇到外来描述符不覆盖，保留失败项；明确恢复我方描述符后才能重试。

关闭可选先引导或先帮助。某一组件失败仍检查另一组件，已成功关闭的不重复执行；子组件失败时引导保护继续保留。先使新回调静默、再实际移除的行为复用原资源所有者。引导资源的恢复失败只重试引导剩余项，不重关两个组件。关闭期间拒绝重复关闭、启动和重试。

frame、DOM和原生输入始终保留。关闭后原文仍可能由原生控件继续编辑，所以不声称原文快照冻结。只是已明确登记的资源退役；模块缓存、样式及整个frame未全部退役。同源文档不是恶意脚本安全边界。无事件脚本往返、外部反射与未登记资源仍不作完整覆盖声明。

真实浏览器通过延迟模块HTTP响应和延迟实际工厂交回，分别验证逻辑取消与物理结束；另覆盖模块失败、已知部分工厂、相反关闭顺序、失败重试、存储描述符冲突、输入及frame标识ABA和原页面继续测算。四种宽度分别检查打开的引导弹窗和关闭后面板，不等于真实手机或原移动端高级设置的完整验收。
