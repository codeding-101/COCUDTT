# 第十一轮：基础概念稳定性核验

日期：2026-10-12。承接费用解释候选；按用户要求先核验基础概念，运费/汇率假设分析顺延。不合并、不更新公开网站。仍限定中国一般贸易进口、单商品一票；没有真实单据或外部专业人员验收。

## 发现和修正

| 基础概念 | 旧实现的问题 | 当前行为及依据 |
|---|---|---|
| FCA指定交货点 | 卖方场所交货后内陆运输仍默认卖方；缺地点也猜归属 | 卖方场所装货交货后运输归买方；其他地点分支仅指运抵指定交货点前运输；地点缺失待确认，整项港杂费不能判断交货前后时待确认。FCA A2/A9/B9 |
| 投保义务和保费承担 | 非CIF/CIP保费一律归买方；通用地点条件可能覆盖保险规则 | CIF/CIP保留卖方投保义务；其他9术语双方无向对方投保义务，不推出实际保费付款方，无明确依据待确认。保险专门规则优先于术语内通用节点条件。A5/B5 |
| 卸货作业和卸货费 | 无卸货作业义务被推成卸货费一定归买方 | DPU保留卖方卸货后交货；CFR/CIF/CPT/CIP/DAP/DDP卸货费用须核合同，资料不足待确认。支付费用不改变风险点。A2/A3/A9/B9 |
| 运费终点和交货风险 | CPT/CIP短驳默认卖方；班轮/舱底名称替代费用范围 | CPT/CIP须核运费终点；CFR/CIF整项目的港费用不凭条款简称判定，上船风险不延至目的地。A2/A4/A9/B9 |
| 报关办理人和费用承担 | 卖方代办清关的事实兜底直接归卖方 | EXW标准费用责任仍为买方；只有代办人、没有适用术语规则时也待确认。另约可覆盖费用，不改风险。EXW A7/B7/B9 |
| 报价和计税 | 单方案允许报价术语错配；商品零/负数量继续测算 | 报价术语必须与方案一致，单商品数量须大于零。零计费量和负费用退款按原字段语义处理。保额不是保费、不加进税基；税费承担不自动产生法定纳税或VAT抵扣资格 |

核对来源为[ICC通用运输规则](https://library.iccwbo.org/content/tfb/BOOKS/BK_0049/BK_0049_04_RulesAny.htm)、[海运及内河规则](https://library.iccwbo.org/content/tfb/BOOKS/BK_0049/BK_0049_05_RulesSea.htm)及[官方引言](https://library.iccwbo.org/content/tfb/BOOKS/BK_0049/BK_0049_03_Introduction.htm)。Incoterms不规定所有权转移、具体付款方式或违约救济；不能从费用/风险模型推定。中国税款公式及保险保额核对规则本轮未扩展。

## 结果与旧项目

结果和内部报告新增可展开的“基础概念核对”。费用规则实现版本1.2；JSON仍0.8，读取0.1–0.7；物流核对和解释仍各1.0。无新增持久化字段，不自动补造合同确认。

旧项目可能改变费用归属或新增待办，原金额/排名不保证不变。未确认费用不计双方已决汇总，参考金额可能偏低，不能作为完整成本或推荐依据。承担方未决的保费仍按计税标记进入税基，不能因归属未决丢失计税组成。输入保留，补资料后重新核对报价和确认状态。

手算夹具补明确的合成合同前提：自愿保险、港口卸货和运费终点分别约定，不充当Incoterms默认，也不进入生产加载/新建。去掉3项从程序节点数导出的概念断言；其他受错误默认影响的断言改为待确认或明确合同条件。

## 验收

- 本地33个文件630项通过。新增基础测试49项，11术语风险、保险、卸货和清关使用独立ICC对照表；覆盖C类风险分离、保险规则优先级、FCA地点缺失、报关代办、卸货合同例外、报价错配、零/负数量和旧文件不补造依据。584减3加49得630，不能写成旧默认概念均无需修改。
- 类型检查、静态审查、静态/离线构建通过。六套Edge脚本通过：基础13项、专业提示、中国进口/来源/运价、独立报价、运输保险、解释图表。无未处理异常。
- 新流程：缺依据→参考；只改归属仍参考；确认合成合同才排名；FCA地点变更使旧依据失效；重新确认但报价不勾稽仍参考，修正报价后恢复；缺地点待确认；数量0阻断及恢复；保存/打开与报告保留行为。
- 1440/768/390/320模拟宽度无横向溢出，320px截图概念说明可读。保存采用API捕获替身，导入采用File/DataTransfer；不证明真实磁盘下载、手机、实际200%浏览器缩放或打印分页。

复现：npm test、npm run typecheck、npm run audit、npm run build:single。隔离启动Edge CDP后设BROWSER_CHECK_PORT和BROWSER_CHECK_OUTPUT，运行node tools/foundations-browser-check.mjs；专业介绍验收另设BROWSER_CHECK_PREVIEW。远程CI以本轮草稿PR对应提交为准，旧CI不代表当前证据。

## 后续稳定性门槛

独立概念对照、错误输入阻断、费用/税基分离、缺依据退出推荐作为后续门槛。随后在不可变副本上做运费及商业/海关汇率假设分析，变化后重跑核对，不把假设当已确认合同；再做客户字段白名单、Excel/PDF/双语导出和真实手机验收。

本轮修复已覆盖问题，不代表全部合同、税法或2026制度获专业认证。多运输段费用关联、付款/所有权、复杂消费税、多商品同票、DDP进口主体限制、优惠原产地/抵扣及完整出口退税等仍需独立建模或专业核验。真实资料暂缺不阻塞工程工作，也不能将合成案例写成实务验收。
