# 第七十五轮：封套工作台与可靠缓存适配验收

2026-10-19。接续[控制器验收](fee-envelope-controller-validation.md)、[内部交接](fee-envelope-handoff-validation.md)和[封套设计](fee-envelope-design.md)。本轮将独立文件与内部审计接入页面，不启用费用应用。

## 入口与使用边界

入口为“高级设置 → 项目资料封套 · 内部交接”，默认折叠。支持：

- 打开独立封套JSON，先显示候选，按控制器分类和必需确认明确采用。冲突不能通过勾选绕过；采用仅替换本面板文件，不安装封套内的项目、账单、配对、成分或精度资料。
- 捕获当前完整来源为历史未知候选；明确新业务名后从当前配对复制新身份候选，撤销已知确认。缺配对时不能退化为旧资料捕获。
- 更新当前封套来源并保留历史；执行前绑定面板租约、父来源原文、外部事件代次及名称，父编辑/来源变化撤销确认。取消与迟到读取不覆盖当前文件。
- 冻结另存完整JSON、导出封套自身的内部HTML/Excel。工作台与封套来源是否一致单独显示；来源不可用时仍可保存独立文件。不将只读历史核对当作业务资格、付款或最新版本证明。
- 检查、明确恢复、明确缓存和移除本机封套缓存；原始文件、无效候选、实际/观察/移除缓存和上次写入原文可分别备份。备份槽只保留最近一份，不是无限撤销。

没有自动缓存、自动恢复、封套来源安装或费用写入。旧计算、责任、风险、税基、利润和客户白名单保持原路径。

## 缓存协议

[浏览器适配器](../src/ui/fee-envelope-storage.ts)仅允许独立封套键。读取无需锁；比较写入和移除必须在同一个命名Web Lock独占区内，精确比较预期原文后同步写入并读回。同值不重复写入。配额/权限/读回异常不自动回滚覆盖可能已经变化的原文。

保证范围是同来源、使用同一锁协议的配合写入者；不声称阻止开发者工具、任意旧脚本、不同设备或外部文件的写入。没有Web Locks时关闭缓存写入和移除，保留文件、只读检查/恢复/备份；不使用普通get/set模拟原子操作。

[工作台](../src/ui/fee-envelope-workspace.ts)独立于全局项目。父来源的未提交编辑、读取、写入或配对失配阻断捕获；其他面板变化通过保守代次撤销确认。storage事件及clear撤销已观察缓存依据，冲突保留两份原文。未保存候选/当前文件、文件或缓存写入期间离开页面有提示。全局异常备份附带独立内存状态与实际原文，但不自动恢复安装。

- [原生浏览器流程](../tools/fee-envelope-browser-check.mjs)40项、1440/768/390/320四种模拟宽度。实际第二标签页持有Web Lock，确认主标签排队后由另一写入者改原文，主标签比较失败且不覆盖；不是用假锁代替浏览器行为。
- 实际下载JSON、HTML、XLSX、原文TXT及全局异常备份；冻结保存期间换候选、取消、迟到原生File.arrayBuffer、项目ABA、配额故障、无锁降级和手机模拟指针操作分别检查。
- 客户简洁/完整两版HTML/XLSX/PDF共六个实际文件，在固定时间条件下逐字节比较封套操作前后，保持一致；项目、账单、配对缓存亦在独立操作前后核对。
- [完整回归运行器](../tools/run-browser-regression.mjs)40套通过；相关14套旧界面脚本统一使用[新文档导航屏障](../tools/browser-document.mjs)，必须等到文档实际替换且加载完成，避免旧DOM被误判为刷新完成；业务断言保持。
- 类型检查、UI绑定、设计反例/指纹检查、目录构建、离线单文件、说明页及证据链接随本轮源码检查。封套设计门禁标记runtimeIntegrated=true、applicationEntryEnabled=false。

窄屏按钮按内容增长，避免多行文字被固定高度截断。模拟宽度和浏览器自动化不等于真实手机验收；真实业务单据、人工专业复核、实际打印继续按用户安排暂缓。
