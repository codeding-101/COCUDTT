# 完整检查失败后的资料保存指引

第九十三轮，2026-10-23。[上一轮实测](fee-capacity-stages-validation.md)确认：合成大资料在捕获阶段超限时，整份工作台检查备份也会失败。原提示不能继续把这条路径当作一定可用的补救。

## 用户可执行的下一步

失败时显示[固定指引](../src/ui/fee-workbench-save-guidance.ts)：保持页面开启，分别定位项目、账单、配对、成分附件、精度选择及封套的原另存按钮。导航仅调用原固定目标，不捕获、保存、采用来源或确认应用；用户仍需在原入口明确另存。资料缺失、未提交或无效时，原入口可以保持不可用。

**六类正式JSON不等于完整工作台备份，不包含全部未提交状态。**提示要求自行记录尚未提交的输入，核对文件及输入后再关闭/刷新页面。内部资料不能直接给客户，下载发起不等于落盘，打开证据也不等于本轮保存。

## 状态与异步边界

| 发生位置 | 提示状态 | 保持与后续 |
|---|---|---|
| 完整预览的捕获、校验或准备失败 | 完整检查未完成 | 本次检查未应用费用；源文件定位指引出现，不猜测一定是大小错误 |
| 检查备份捕获或编码失败 | 备份未生成 | 写入器未调用；提示整份备份可能与检查受同一限制 |
| 保存器返回原生或普通AbortError | 另存取消 | 不宣称已保存，六类文件证据保持 |
| 保存器异常或返回未识别结果 | 保存未确认 | 不宣称没有写入任何字节，先核对目标文件后再重试 |
| 保存器返回SAVED / DOWNLOAD_STARTED | 分别说明已另存 / 仅发起下载 | 检查备份不标记项目或封套已保存 |
| 等待保存期间取消、资料变化或A→B→A | 丢弃迟到的提示更新 | 原代次继续有效；旧完成不能覆盖新的取消/检查状态 |

[工作区](../src/ui/fee-envelope-workspace.ts)只新增展示状态；它不进入捕获的保留语义根，也不进入正式文件。原所有者仍接收界面状态变更并撤销旧检查点，不能误写成“界面操作不改变所有者修订”。预览/确认、来源资格、原子费用与回执、客户重新确认仍走原实现；异步备份沿用原检查代次，不引入可序列化确认资格。

指引的六个固定目标复用[原导航](../src/ui/fee-workflow-guide.ts)与原手机设置路由：高级设置内的成分/精度/封套保留在抽屉，项目/账单/配对定位到原页；不会复制第二份业务表单或自动点击另存。未知目标、继承键与任意选择器拒绝。

## 验证门槛

[27项专项测试](../tests/fee-workbench-save-guidance.test.ts)覆盖原严格复制拒绝、编码失败、取消/不确定保存、未知返回值、连点、迟到完成、ABA、显式重试及固定导航。[原生页面检查器](../tools/check-fee-save-guidance-browser.mjs)在正式离线页面重验1/4/8笔合成资料，检查四种宽度和六类原按钮的焦点、无自动保存及原来源保持。保存API与文件输入为明确测试替身，不证明磁盘或真实手机。

新产物须重新跑原46套完整浏览器流程及69个捕获对照场景；历史第九十一、九十二轮报告和测量值原样保留。[资格说明器](../tools/fee-save-guidance-evidence.mjs)只放行列明的界面/门禁变更，并要求当前完整证据与源指纹，不能把历史时间重新标成新产物测量。[验收记录](fee-save-guidance-validation.md)列明当前结果和未完成项。
