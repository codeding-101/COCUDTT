# 第六十七轮：精度文件交接、草稿恢复与内部审计验收

2026-10-18。承接[独立文件1.0](fee-precision-selection-file-validation.md)，实现[编辑原文模块](../src/data/fee-precision-selection-editor.ts)、[独立控制器](../src/ui/fee-precision-selection-controller.ts)与[内部快照](../src/data/fee-precision-selection-snapshot.ts)。这是可注入环境的开发API，**未注册工作台、全局存储监听或自动草稿入口**，没有新页面控件或费用应用。文件1.0、Schema和模板保持。

## 已实现的交接规则

| 操作 | 结果与限制 |
|---|---|
| 打开／采用 | 完整验证后只预览，明确采用才替换独立面板文件；不安装内嵌项目/成分附件。操作令牌、内存epoch和两份实时来源原文共同阻断迟到结果，包括预览后来源变化 |
| 新建／明确提交 | 新建只取当前完整双来源；提交前重验编辑租约、来源和完整输入。已有记录只改choice，新记录只收组件ID/通道/choice，不接收原金额或可信候选 |
| 政策回执／重绑／删除 | 复用文件API；编辑未提交时阻断，来源/金额/CORE精度及税务待办不清除，不改变原业务 |
| 另存 | 冻结点击时文档；等待期间的新编辑/新文档保留。只有SAVED且当前完整内容仍相同、无编辑时标记保存；DOWNLOAD_STARTED只表示已发起，取消/失败/非法结果均不伪造落盘 |
| 恢复 | 两槽均完整检查后预览，明确恢复前重读两份原文、令牌、内存和双来源；不会自动重绑/确认。旧编辑租约或槽位失配可保留供备份，不能直接提交 |
| 离线分支 | 同身份旧修订或同修订不同内容拒绝回退当前文档，保留两份资料；不自动合并或选“最新文件名” |
| 备份 | 原始槽位逐份TXT备份；完整内存备份含selection_json及未提交editor_json，冻结生成，不修改保存状态。备份0.1封套不是精度文件1.0，不能混用导入 |

环境提供currentSources、blocked、storage、write和changed，不访问全局localStorage或自动安装项目。blocked异常时拒绝操作，渲染通知失败不锁死；通知防递归。当前来源只作原文匹配，不凭文件名、显示金额或业务名称续用回执。

## 编辑与两份独立草稿

两个新键为`trade-cost-engine:fee-precision-selection-v1`及`trade-cost-engine:fee-precision-selection-editor-v1`；仅在未来显式注册控制器时使用。构造不读写存储，既有项目/附件草稿键不触碰。

编辑为`INTERNAL_FEE_PRECISION_SELECTION_EDITOR / 0.1`，绑定selection_id、basis_revision/content_sha256、双来源SHA-256和record_id/完整组件通道slot；原文record_json允许未完成，只有显式提交才严格解析。已有记录原文仅为choice，不编辑原值/目标/槽位。新记录slot为null，明确提交后由文件API捕获原成分；64KiB原文字节、256KiB封套及UTF-8/代理项/描述符边界分别检查，不截断原文。

首次观察非空草稿即保护，不能因新建而覆盖旧资料。每次写前重读匹配先前原文，写后读回；未收到storage事件也检查。部分写失败不自动清理另一槽旧编辑，内存新记录保留并提示备份。跨标签冲突、不可读/配额失败、坏草稿、孤立编辑均保留原文；明确放弃须精确原文匹配。回调重入期间出现新编辑不被后续清空，放弃期间的内存变化标记WRITE_INTERRUPTED。

这是逐槽原文比较和读回保护，**不是跨标签原子事务、全局锁或新业务真实性认证**。异步环境和同一离线文件可形成分支，不能据修订或SHA认定现实中的“唯一最新”。当前未执行浏览器配额、真实文件选择器/下载或全局storage事件验收。

## 内部审计与客户隔离

JSON快照包含完整已提交精度文件及实时复核；HTML和独立Excel工作表展示原/候选币种、通道、原精确分数、候选、正负差额、政策状态和原待办，并保留完整原文、来源与逐步算术审计。不合计不同通道/币种，未知为“未知”，历史来源失配醒目标注。未提交编辑不混入正式快照，只出现在明确内存备份中。

HTML只用转义文字，无执行脚本或外部资源；Excel金额、政策及JSON全部作为文本单元格，前导等号不生成公式或外部链接。按240码点分片可重建完整文件和审计。Excel使用独立8MiB预算，先限制完整文件，再限制含审计的完整快照；超限明确拒绝，不截断。完整文件仍可单独备份。此预算不是浏览器存储上限或性能证明。

[真实客户文件测试](../tests/fee-precision-selection-snapshot.test.ts)在项目扩展和公开投影对象中植入完整有效精度文件、内嵌配对/成分凭证、未提交编辑及metadata哨兵。full/compact均实际生成HTML/XLSX/PDF，与未注入内部资料的基准HTML原文和二进制SHA-256一致；另检查解压XML、PDF解码对象、标题/作者及无附件/动作/表单/XMP目录。该差分验证避免只搜明文而漏掉PDF字体编码中的文字。不代表自动识别用户主动填入公开字段的敏感语义，也未新开客户精度输出入口。
