# 控件证据的保留预算与重复副本清理

2026-11-02，第117轮，本地只读诊断。新增有上限的控件证据账本及DOM适配器，不改[旧观测记录](fee-workbench-boundaries-design.md)或[分项交接规则](fee-workbench-handoff-design.md)，不接入正式运行文件。

默认最多保留4096个控件、8 MiB原文UTF-8字节、65536个勾选/多选状态和128个File对象引用。可以降低测试预算，不能提高这些默认值。先计算整项更新是否容纳，再复制数组和替换记录；基线与不同的最近值都计入，恢复相同基线可复用原记录，但变化历史不会因此清空。File仅计引用，不读取内容或文件名。

这些是诊断账本的逻辑证据预算，**不是JavaScript堆、DOM、File内容或浏览器总内存的上限**；未测量峰值内存或性能。来源核对只保存小型绑定及单个待确认的上下文，不逐控件保留整份旧项目。达到上限时保留已记录证据，永久失效本次观测，解绑自己的六个root输入监听器和MutationObserver；不再完整记录后续输入。原页面、业务和原监听器继续保留，不能据此继续签发交接或切换身份。

清理只针对已移出页面、初始就由可信已提交来源精确匹配、期间没有输入事件/值变化/读取失败/属性变化、且当前仍匹配同一字段的重复旧控件。初始未知不能因后来相等就升级；变动后改回、坏数字、文件选择及曾无法读取的控件继续保护。当前原生来源证明仅覆盖商品数量，其他字段仍为未知。只清理重复UI证据，不清除业务待保存，也不证明源文件已落盘。

准备、明确勾选与清理分开。身份绑定签发者、账本代次、控件引用、字段和原值以及当前来源上下文；复制/跨实例/新准备/撤回/ABA都撤销旧身份。确认前同步重读全部候选并检查来源，全部通过后才一次删除；部分失败或重入变化不能先删一部分。UI原生属性被额外描述符遮蔽时记为未知，不调用额外getter。

外部/反射/无事件脚本ABA、所有DOM、自动/外部资源和完整工作台安装继续未证明。停止诊断释放自己的引用不代表原数据已保存或允许关闭页面。原财税规则、文件格式、依赖、业务/恢复预算和离线产物保持。

见[账本](../tools/fee-workbench-retention.ts)、[DOM适配器](../tools/fee-workbench-retention-dom.ts)、[面板](../tools/fee-workbench-retention-panel.ts)、[测试](../tests/fee-workbench-retention.test.ts)、[验收](fee-workbench-retention-validation.md)与[后续目标](development-stages.md)。

最后来源核对回调后重新检查本地代次、私有清理身份、停止状态与勾选状态；准备和取消也推进代次，避免准备/取消往返仍接受旧选择。10项对应回归修复前失败、修复后通过。
初次来源证明回调如同步改变账本，外层更新不再写回：停止本次观测并保留较新的内层记录，避免覆盖及保留计数失衡。该重入保护不依赖来源所有者是否同时推进代次。
