# 第四十五轮：新手／专业工作台验收

2026-10-15，基线main为第四十四轮。目标是重构信息架构与视觉、减少首用字段、提供明确的计算反馈；本轮不改变费用、风险、计税及比较算法，不新增业务文件版本或依赖。

## 实现

- 默认新手模式，独立本机偏好；专业模式完整展示，四种比较基准保持。模式切换不改项目、来源、草稿和保存状态；偏好读取/写入失败不会导致界面故障。
- 快速入口、核心输入、当前结果、高级设置、业务交接和帮助顺序；运保费可直达原费用明细，复杂费用未做合并的快捷金额。
- 摘要读取实际引擎汇总，未知采购成本和不适用退税分别显示。当前报价与反推比较区分；完整公式、税基和归属沿用已有记录。
- 未提交输入标记待更新、隐藏旧金额、暂停结果导出，保存前先提交当前输入；失焦或回车重算。多项可定位修正提示及原错误编码并存，收起祖先面板会同步展开。
- 重新设计吸顶栏、导出菜单、表单、结果区与移动列布局。模式偏好不进入项目、配对或客户文件；所有专业数据继续参与计算。
