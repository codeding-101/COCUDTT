# 第八十三轮：可下载合成练习资料与应用后连续核对

2026-10-20。承接[八步操作导航](fee-workflow-guide-validation.md)。本轮增加独立合成ZIP资料包，贯通实际下载、原面板打开、待办检查；补验真实应用后的旧选择移除、已有引用和两份附件重绑。计算、格式与财务门槛保持，不提供合成业务的费用批准或真实税务结论。

## 入口与资料

在“业务资料与交接 → 费用工作流”点击“下载合成练习包（ZIP）”。解压后先读README.md，再选择一组练习。三组是独立案例，不是同一业务的前后修订；重复下载创建独立资料身份，不能充当原业务后续文件。

| 案例目录 | 项目初始条件 | 配对选择 | 条件手算中的新增变化 |
|---|---|---|---|
| 01-new | 尚无113 USD服务费 | 拟新增113 USD | 791 CNY |
| 02-reference | 已预置113 USD服务费 | 只引用已有费用 | 0 |
| 03-mixed | 已预置113 USD；20 USD未计入 | 引用113、拟新增20 USD | 140 CNY |

手算只在来源、历史、资格完整，新增项由买方承担、报价未含、海关排除且无抵扣，明确商业换算1 USD=7 CNY且其他条件保持时成立。不是本包已经可应用、真实海关处理或税务资格的结论。包内成分仍UNKNOWN，未知利润保持未知。汇率和中国进口项目沿用固定虚构示例，不是市场/海关数值推荐，本轮未重查法规。

每组有六份现有正式格式的project.json、bill.json、pair.json、attachment.json、precision.json、envelope.json。配对嵌入同组项目和账单，附件和精度逐字引用相同来源，封套记录同组全部来源。账单/提案/汇率与成分来源标为EXAMPLE，没有用户确认；拆税、抵扣、海关成分UNKNOWN，现金政策UNRESOLVED。封套为UNKNOWN_IMPORTED，回执为空；完整预览应阻断，不显示可应用候选。不得为跑通练习改成确认或复制新业务绕过旧历史。

ZIP共20份文件：18份正式JSON、README.md及manifest.json。清单仅记录19份内容的UTF8字节数和SHA-256、案例用途及无财务权限标记；它是包索引，不是新的业务格式、来源认证或可导入授权。ZIP和manifest不能当项目JSON打开。源文件使用各自已有解析器，不增加包导入器或回放入口。

## 下载与打开边界

[构建器](../src/data/fee-workflow-exercises.ts)不接收当前交易，使用现有正式构造/序列化API产生独立资料，不调用来源确认、政策确认或费用事务。应用只在点击后生成ZIP；双击和并行导出沿用资源忙碌保护。另存成功、取消、失败或只发起下载均不改变当前费用、来源或项目保存证据。等待另存期间用户新修改保留，不能被练习文件的迟到保存标为已保存。

打开前先分别备份当前项目和独立资料。在配对面板打开pair.json会明确安装其中项目与账单；在原成分、精度和封套面板依次打开同组文件并明确采用，各自只替换所属面板。下载本身不安装任何来源，也不自动采用文件。来源存在和可解析不能代替费用资格。

## 应用后连续核对

使用独立的已合格软件测试夹具验证原有真实应用，不能用本练习的EXAMPLE资料冒充该夹具。应用后原CREATE_NEW配对与成分/精度文件保留历史，项目已有费用及回执保持。后续依次明确移除旧选择（退休映射保留）、将账单绑定当前项目、填写并核对已有费用引用、捕获新配对修订并加入引用。新引用取得新映射，原映射不复用。

附件重绑撤销三项来源确认，精度重绑撤销算术政策确认；原记录仍指向旧映射，可能显示ORPHAN_TARGET，不自动按费用ID或名称换目标。确需新目标须明确删除旧记录并新增，退休编号保留；需要新成分的精度记录同样另行处理。本轮验证到“旧目标悬空、来源待重新核对”的安全状态，完整替换记录后再次报价的连续验收继续在下一阶段。

核对、重绑及明确更新封套来源都应保留已应用费用与原回执，应用恢复备份逐字保持，旧客户确认仍撤销。资料未完成不能再次应用；保存或显示失败不撤销已应用事实，恢复备份不重放费用。

- [原生浏览器验收](../tools/fee-workflow-exercises-browser-check.mjs)核对实际ZIP下载、指纹、取消/迟到另存、原输入打开及实际应用后的原界面连续操作。文件上传和取消/延迟另存使用API替身；实际ZIP下载单独检查。四种屏宽是模拟布局，不等于真实手机。
