# 本地 Excel 导出验收（第十四轮）

## 交付与用途

两个明确入口：客户预览区“导出客户报价 Excel 草稿”和顶部“导出内部成本 Excel”。生成原生 .xlsx，不以改扩展名的HTML/CSV冒充工作簿，不上传交易数据或使用CDN。客户仍须先检查公开内容；编辑项目或公开字段撤销检查，新建/打开重置。导出不保存项目，也不改变草稿、文件名、dirty或来源确认。选择文件期间编辑项目，不改变此前生成的不可变文件内容。

客户文件只接受 CustomerQuote 的枚举字段并逐格重建，不自动带出采购成本、利润、净价、内部名称、费用备注、来源/保单/承运合同或项目JSON；全部ZIP部件（含关系及元数据）解压扫描验证。用户主动填写的公开文字和商品名称仍须人工内容审查。客户一个工作表，显示实际原币总额、数量/单位、条款及标准提示、有效期和待办；始终标为草稿，不从模拟价格反推对外承诺。

内部工作表：交易口径、方案对比、费用明细、税费与公式、来源与待办、输入快照；启用假设时另有假设分析。逐术语复用完整比较输出，当前列失败也可存档其他可计算列；失效列不沿用引擎占位零。费用记录原币/核算金额、归属、实际计入方、去重排除和未启用状态。完税价格组成独立于费用汇总；采购成本不混入其他卖方费用合计。中国进口不适用中国出口退税，以“不适用”表达；未知采购成本/利润不补零。公式及代入值是引擎解释文本，比例等结果不统一标成金额。假设仅供参考，非法参数保留原因而不替代实际基准。

## 文件与精度

Excel为生成时静态快照，没有动态计算公式；编辑表格不会重跑引擎。可信数值用原生数值单元格，十进制文本直接写入XML，不经JavaScript浮点重算。超过15位有效数字或12位小数时以文本保留完整值，并在口径说明提示；原币12345.1234567保留，1234567890123456不因Excel限制改写。币种/单位明确独立列，源日期为可读ISO文本，不承诺Excel日期筛选/再计算模板。百分比列存的是变化百分数（如10表示10%），标题写明%。

自由文本明确写入inlineStr，没有<f>公式节点，无外链、批注、宏、隐藏工作表及作者元数据。保护OOXML _xHHHH_字面量，编码XML控制字符，XML转义；=、+、-、@及制表符开头文本不会执行。中文长文本按240字符续行，完整保留，冻结首行及关键列，设置列宽/行高/自动换行；输入JSON按Unicode码点分片，逐行拼接回原文件，emoji边界不损坏。超过100000物理行、64列、非法表名/列数/冻结范围明确拒绝，失败不下载半成品。

仅新增锁定fflate 0.8.3用于ZIP生成；未把整个表格编辑器或网络依赖放入离线工具。[fflate官方ZIP API](https://github.com/101arrowz/fflate/blob/master/docs/functions/zipSync.md)。核心贸易、税额、退税和利润算法未改，文件格式0.8、费用规则1.2、客户说明1.0保持。

## 验证证据与限制

- 新增39项：工作簿34项、真实UI事件5项；全部36文件756项通过。覆盖全ZIP部件隐私探针、公式注入、数值/文本类型与精度、未知利润、逐项费用/比较金额、商业/海关汇率分离、失败列、假设失败、JSON/emoji往返、长文本续行、无效尺寸与冻结范围、检查失效、异步快照、取消、失败与下载回退。
- 新Excel Edge流程16项：原生金额、公开文件名、内部数据保留/客户排除、检查失效、精度文本、取消/写盘失败、草稿保护、模拟阻断和实际无头浏览器下载。1440/768/390/320无横向溢出，异常0。九套浏览器流程包含此前八套完整回归；真实下载会产生Edge下载内部页，调试目标选择已排除该内部页。
- Microsoft Excel 16.0独立隐藏实例只读打开客户/内部/精度合成文件：各工作表无可执行公式/外链，金额10000为数值，超精度为文本，=1+1是文字，Unicode及_x0001_原样，内部JSON拼接一致、未知利润仍为未知。客户Excel打印预览已检查中文排版；此验收辅助预览不算应用PDF导出完成。
- 503笔合成费用导出约253ms、290868字节，输入不变；这是本机Node单次记录，不是手机性能或普遍速度承诺。记录在交付证据目录的large-workbook-check.json。
- 类型检查、静态绑定与离线构建通过。远程Windows/Linux CI以本轮草稿PR实际提交记录为准，不引用旧提交冒充当前通过。
- 直接写盘API仍用内容捕获/故障替身；真正<a download>产生的文件已读取解压核对。LibreOffice、真实手机下载/分享、长表打印分页、真实业务与专业复核仍待验收。假设在Excel里是参考快照，不成为动态情景模型。
