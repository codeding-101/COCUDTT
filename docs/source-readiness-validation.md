# 来源与排名：现状分析、执行计划及验收

日期：2026-10-11。目标用户：外贸业务人员；首条支持路线：中国一般贸易进口、单商品一票。此轮改动在本地，尚未部署。

本文保留第三轮0.3格式及397项测试的历史验收记录。当前格式0.5、449项测试，后续进展见 [业务前提验收](import-context-validation.md)、[买方流程与报告验收](buyer-workflow-validation.md) 和 [后续展望](project-outlook.md)。下表中原定“下一阶段”已有部分完成，以新文档为准。

## 现状判断

项目已有11种术语比较、十进制计算、费用承担判定、独立汇率和离线存档能力。前两轮已保护文件与草稿，并建立明确的中国进口计税口径，368项测试通过。当前适合继续开发和复核示例，尚缺真实业务验收证据。

本轮开始时的直接缺口：税率与汇率没有人工来源核对记录；可计算的方案即使漏计待确认费用也可能进入最优排名。业务人员需要知道金额依据和未解决事项，才能判断比较是否成立。因此本轮优先补齐来源与排名条件。

- `npm test`：25个测试文件、397项测试全部通过。
- `npm run build:single`：类型检查、Vite构建、最终内联脚本语法检查通过；更新根目录离线HTML。
- `npm run audit`：静态审查通过。该审查针对源码约束，不能认证税率、来源或业务资格。
- Edge通过file://加载最终产物，验证中国示例的买方总支付为901101.49，示例不参与排名；填写合成来源并确认后可排名；修改汇率撤销确认；恢复并重新确认后可排名。
- 浏览器中保存API替身收集JSON，再通过真实文件输入事件重新打开：0.3版本、来源、状态和快照保留，排名状态恢复。此项证明浏览器数据流程，未证明真实磁盘写入或下载完成。
- 申报日期超出海关汇率有效期时阻断计算，纠正后恢复；坏文件导入保留草稿与结果。
- 1440px桌面、390px和320px手机模拟视口均无页面横向溢出；来源及结果面板展开后也通过；无未处理运行异常。未进行手机硬件、多浏览器验收。

## 如何复现浏览器检查

需要Node支持全局WebSocket，并安装Edge或Chrome。先构建，然后在独立测试配置目录启动浏览器；检查脚本会加载项目文件、重置测试草稿，因此请使用独立配置。

PowerShell示例：

```powershell
npm run build:single
$validationProfile = Join-Path $env:TEMP 'cocudtt-china-import-validation'
Start-Process -FilePath 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe' -WindowStyle Hidden -ArgumentList @('--headless=new', '--no-first-run', '--remote-debugging-port=9317', ('--user-data-dir="' + $validationProfile + '"'), 'about:blank')
node tools/china-import-browser-check.mjs
```

默认输出至系统临时目录的`cocudtt-browser-check`，包含JSON报告及桌面/手机截图。可通过`BROWSER_CHECK_PORT`和`BROWSER_CHECK_OUTPUT`设置调试端口和输出目录。检查后关闭该独立浏览器进程。

## 下一阶段安排

| 顺序 | 工作 | 完成条件 |
|---|---|---|
| 1 | 三笔真实匿名中国进口案例 | 收集商品、原产地、申报日期、运保费、正式税率/汇率来源与实际税额；逐项对照计算并解释差异；包含至少一笔适用消费税的支持范围内案例 |
| 2 | 国家、原产地与待遇条件 | 明确出口国、进口国、原产国和申报制度；协定待遇及VAT抵扣有独立人工核对项；条件缺失时不作已核实结论 |
| 3 | CI与发布核验 | 每个PR自动运行测试、静态审查、类型检查与单文件构建；发布前同步远程历史并复核离线及线上产物 |
| 4 | 内部测算报告与业务员试用 | 报告保留输入、口径、来源、待办及结果；3–5位目标用户完成同一报价任务，记录真实完成率、耗时和误填位置 |

真实案例需要用户或合作业务人员提供已脱敏单据及适用条件，不能用虚构样例替代。下一阶段也应检查比较中的方案专属运价与待确认费用敏感性，使同一环节由不同方组织时的金额可以分别比较。

## 当前检查的边界

程序只检查人工记录是否完整、适用日期是否覆盖、数据是否仍与确认快照一致；不会访问来源链接核实内容，不判断归类、原产地、协定待遇或抵扣资格。第三轮没有新增税法规则。旧LEGACY模式仍不要求来源核对，需切换到中国进口模式才能使用本轮完整检查。

跨术语比较仍固定货物净价、数量、运保费和税基事实；不表示所有真实交易换术语后税额都相同。卖方利润依据录入成本，境外税务未建模。中国模式的其他业务边界见中国进口规则与验收文档。
