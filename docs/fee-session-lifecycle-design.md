# 独立会话生命周期与关闭保护

2026-11-01，第113轮，本地原型。只关闭本轮明确持有的独立会话，不安装原完整工作台，不写费用、利润、税基或新确认。原财税/贸易引擎、项目/付款/交接文件格式及默认容量保持。

关闭权限绑定当前管理器、会话、业务修订、付款/表单修订及任务代次；复制、跨会话、取消与输入/任务ABA使旧关闭核对失效。未提交输入、未完整交接提交和未被表单接收的文字分别列明；未知观测或物理任务仍在运行时不允许关闭。有资料需要保留时，必须在当前关闭核对中明确确认放弃；取消关闭只撤销关闭意图，不修改业务或客户核对。

取消任务与放弃资料是两个操作。取消立即撤销逻辑权限，但完整交接、客户写入、分项下载、付款文件读取和打开任务的槽位保留到实际工作结束。期间编辑区不可交互；结束后重新准备关闭，不自动丢弃。默认下载适配器将一秒URL回收宽限计时包含在返回的Promise内，清除计时及URL后才释放任务；注入适配器也须在实际工作和自有资源清理结束后完成Promise。已发起的浏览器下载无法撤回，取消不会伪造保存成功，也不采用迟到候选。

原生input事件捕获全部当前独立表单文字，已被业务草稿接收的值由原模型管理；未被接收的值单独保留并可复制，完整模型文件保存不能清除这类缓冲。明确放弃后迟到的同值文本change事件不重新登记旧文字。长文字按原限制拒绝，不截断为合法值。

beforeunload只在有未提交、未交接、未接受文字或运行任务时绑定，干净保存与关闭时移除。范围是本面板原生交互及明确refresh；外部直接修改控制器后须刷新，不声称已订阅原完整工作台的全部程序化变更。浏览器可能不在移动端、强制终止或无用户手势时显示提醒，不能保证阻止关闭或替代备份。页面卸载不能等待任意异步任务；本页面内的明确关闭流程才等待物理结束。

只有当前完整文件回执的明确保存确认能清除对应内部修改；客户及分项下载不能替代。原生监听器、旧面板监听器与对象URL在专用浏览器中检查，测试不等同全工作台资源释放、容量或性能验证。见[验收](fee-session-lifecycle-validation.md)、[控制器](../tools/fee-session-lifecycle.ts)、[测试](../tests/fee-session-lifecycle.test.ts)与[阶段计划](development-stages.md)。
