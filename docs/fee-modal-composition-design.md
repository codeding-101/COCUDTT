# 受限组件组合设计

2026-11-05，第126轮，本地候选。复用原高级设置、字段说明与四步引导的源码，只在本机诊断响应中适配查询、唯一ID、监听器登记、会话偏好和滚动锁；原src与正式工具字节保持。三个副本在受信同源子文档组合，不授予费用写入、保存确认或工作台安装权限。

[范围适配](../tools/fee-modal-composition-source.ts)逐份核对固定原源码和完整往返，保留真正的原生dialog开关。移动面板使用同一棵控件树；document查询只查所属根，只有占位div创建能力，丢失父节点时回到自己的根。项目打开/保存按钮在副本中禁用。引导偏好仅保留在本次副本会话；不会访问浏览器存储。

[共享滚动锁](../tools/fee-modal-composition-locks.ts)为明确登记的持有者签发私有身份，最多16条；只在首个持有者打开时保存两轴原值及优先级，最后一个退出时按轴恢复。相反关闭顺序不会把另一个已登记持有者的hidden当作自己的旧样式。外部改成其他值或优先级的轴保持；未登记脚本写相同值的往返仍未知，不声称完整样式来源追踪。失败写入或恢复保留已知令牌；该令牌不会供下一次打开继续使用，就绪签发也会拒绝。明确清理失败资源后再继续，输入与File仍保留。

[组合副本](../tools/fee-modal-composition-scope.ts)复用既有两组件会话协议，移动面板属于先创建、最后关闭的bootstrap。模块或工厂实际未结束前保留等待；迟到模块不继续创建，迟到工厂交回的句柄继续保留和清理。已成功关闭的组件不重复关闭；失败资源先静默、保留，并明确重试剩余项。

焦点优先留在仍打开的所属弹窗，按真实触发控件恢复；不夺取外来原生弹窗的焦点。有上层弹窗时，底层重绘和替换先拒绝，保留输入，先关闭上层再重试。同项目重绘移动原节点而不克隆File；明确替换合成表单会保留一组旧原文和File，新表单不继承选择。旧输入组上限为1，超限拒绝，不删除旧组来腾位置。它不是业务文件格式或费用容量上限变更，也不是完整业务切换。

仅清理明确登记的监听器、弹窗、观察器、滚动令牌及存储描述符保护。保留DOM、未提交原文和File，原工作台继续编辑计算；不把关闭等同于已保存，不宣称整个frame退役、全部外来资源可撤销、任意DOM异常原子性或恶意脚本隔离。完整工作台切换、原应用整体解绑和最后单次安装继续独立验收。
