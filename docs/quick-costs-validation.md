# 第四十六轮：运保费快捷录入与字段帮助验收

2026-10-15。工作台第二阶段首批交付，适用范围是编辑已有费用与解释已有字段，不扩展费用、税务或术语规则。真实业务单据、真实手机及人工专业复核仍未验收。

## 交付范围与写入路径

核心输入下方提供“快捷修改主要运费与保险费”。面板默认收起，运费和保险分别明确选择既有记录；即使只有一笔也不自动选择。分类依据为结构化费用类别，不根据名称猜测。多行逐笔选择，不展示虚构的合并输入。

只有当前术语活动、USER来源、固定或实际计价且没有复杂关系的记录可以编辑。重复ID、衍生/货值项目、其他计价方式、父项包含、被包含或作为其他费用基数、互斥/去重组、集装箱或港费范围均保留只读和原因，可返回完整明细核对。界面不会创建费用、猜承担方、同步货值/报价或改变关系。

快捷金额保持原币原始文本，经已有 `onItemField` 和 `commit` 管线处理。空值保留空值并阻断计算，不补零；沿用输入校验、来源确认失效、运输/账单绑定失效、客户预览失效、草稿及保存路径。快捷选择和渲染修订仅在内存，项目替换/重开/刷新清除选择；旧DOM事件、伪造目标或发生关系变化后的事件重新校验，不写错行。

同时修正完整明细中的显示标签：换算后的金额标核算币种，原币输入仍保持原值。未在展示层重新计算汇率或利润。

## 字段帮助和键盘

七类帮助为货值/报价、比较基准、商业/海关汇率、费用归属与报价包含、运输变形、中国进口税务、来源确认。问号在原标签外，不复制输入字段；文本不读取业务数据。快捷面板和完整字段均可打开。

原生模态弹窗具有标题、说明及关闭按钮，Tab/Shift+Tab限制在按钮内；Escape或关闭返回当前触发按钮。点击帮助或保存前提交正在输入的金额，重绘后弹窗仍保留；异常恢复先关闭弹窗，避免挡住恢复操作。帮助状态不进入项目、配对或客户文件。

帮助强调费用承担、付款、风险、报价包含及海关加计分别核对；运输变形字段不会自动改写本工具的风险点，不据此推断所有合同约定。来源检查不认证法律效力。未新增法规符合性或专业认证结论。
