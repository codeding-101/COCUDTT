# 交接前核对与分项已提交文本复制

2026-11-01，第116轮，本地独立面板。基于[输入边界观测](fee-workbench-boundaries-design.md)，只复制当前可取得的六类已提交来源原文：项目、账单、配对、成分附件、精度选择和封套。格式和原文不改，不打包成新的完整恢复格式，不安装或关闭原工作台。

每次只准备一份原文，选择及确认绑定当前私有观测、所选原文、原保存记录和本次代次。复制/跨面板/新准备/取消/已观测ABA都使旧身份无效；无事件脚本或外部反射往返仍不能证明覆盖，完整新鲜性继续关闭。预览不包含原文，只包含来源类别、UTF-8字节、保存记录状态和待办。

原保存记录分缺失、未知、与当前文本一致和对应其他文本。记录一致也不独立证明操作系统落盘。下载发起、写入接口报告SAVED和用户检查所选文件分开；用户声明仅属于这份副本，不写原files.saved_raw，不清除未提交或移出的控件，不清除旧保存待办，不批准客户文件。六份分项文本也不等于完整工作台备份。

文件任务实际结束前保持忙碌，重复下载、另一次准备和面板销毁拒绝。撤回核对不冒充取消已经开始的物理下载；迟到交付仍可记录结果，但没有当前确认身份。写入失败保留原来源并转交原错误。复用原一秒URL回收下载函数，待计时与URL回收结束才返回。

这里等待的是本面板写入API与资源回收工作，不代表浏览器或操作系统已经完成下载落盘；DOWNLOAD_STARTED仍需用户另行检查。本面板销毁也不等于关闭原应用或证明可以刷新页面。

源码盘点区分23处原应用资源调用与4处本面板下载资源调用。原应用监听器、任务、URL继续保留，没有清理权限；计数安静不能证明解绑。仅在本机Vite响应中适配旧下载函数的四个调用点，用独立账本验证自己的计时器和URL，不写原源码、不包装原生事件回调、不全局补丁；计时器沿旧观测适配器转发接收方与参数。保存未知、全部DOM、外部/自动资源、诊断保留上限及最终安装仍列为未实现条件。

新交接所有者最多保留一份所选原文，单份不超过64 MiB，旧身份在新准备/取消时退役；这是独立诊断保护，不改变原导入、恢复、链预算或业务容量。原root控件观测仍未验证长期保留的内存增长，正式接入前必须处理，不能丢掉变动控件来清理计数。
