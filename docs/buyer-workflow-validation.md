# 中国进口买方流程、报告与案例验证

日期：2026-10-11；格式0.5。真实脱敏交易暂未取得，本轮继续功能与工程验证。下述合成输入不代表报关验收、实际税率或真实优惠资格。

## 已完成的日常工作流

1. 点击“新建中国进口”，商品、数量、货值、报价、采购成本、税率、日期、路线、费用和汇率均从空白开始；默认CNY、海运和CIF仅作可修改选项。
2. 填写货物净价、合同报价、运保费，确认货值不含运保费。含运保费的货值会阻断计算，避免再次加计；未确认口径只作参考，不参与排名。独立净价参与报价对账，已有货值费用行不会重复相加。
3. 新增费用的金额、数量、单价、天数或百分比不预填零。缺失输入会提示；确实没有费用时可明确填0。
4. 未知卖方采购成本可以留空：买方支付及税额照常测算，采购成本显示“未知”、利润显示“无法评估”，不产生卖方利润最优结论。明确填写0与未知有区别。固定目标利润率需要已知采购成本，否则提示换用其他比较基准。旧税务模式仍要求采购成本，避免破坏原退税假设。
5. 核对来源和业务条件后比较方案；未核对、变更后过期的确认或不支持的制度仍会退出排名。
6. 保存项目JSON以便继续编辑；导出HTML测算报告供同事离线查看和打印。

## 报告范围

报告重新计算生成时的结果，包含输入概览、贸易路线、税务口径、费用归属、税额、各术语比较、实际使用的来源、适用期、人工核对状态及待办。完整项目JSON作为纯文本输入快照附在文末；无需脚本或外部资源。

结果中的依据和待办默认展开，打印样式采用A4横向；完整输入快照默认折叠，可自行展开后打印。后来编辑项目不会改变已导出的报告。报告取消或写入失败不触发替代下载，不把项目标记为已保存，草稿保持不变。

当前报告复用结果中的计税组成和税额，人工算式保存在案例清单；暂未提供逐笔公式展开或表格导出。报告保存仍不能替代项目JSON正式存档。

## 结构化案例验收入口

默认目录`tests/fixtures/import-cases`包含三对`.case.json`清单和`.project.json`项目：

| 案例 | 验证重点 | 预期买方总支付 |
|---|---|---|
| cif-dual-fx | 商业汇率与海关汇率不同，CIF运保费计税 | 901,101.49 CNY |
| consumption-rounding | 从价消费税及逐税种舍入 | 1,627.56 CNY |
| specific-duty | 明确KG单位的从量关税 | 1,299.50 CNY |

所有默认案例均标为SYNTHETIC，保留示例来源状态并退出排名。命令逐项比较计税价格、关税、消费税、VAT、买方总支付及扣除可抵扣税后的成本，使用精确Decimal金额，不用浮点误差容忍掩盖差异：

```bash
node tools/check-import-cases.mjs
node tools/check-import-cases.mjs /absolute/path/to/private-cases
```

外部目录每笔案例需有项目文件、资料索引、复核人和日期、人工算式及六项到分的预期金额。真实脱敏资料标ANONYMIZED_REAL，同时满足当前排名检查；这只核对已录数据与预期，不验证单据真实性或原产地资格。可参照默认清单结构和[采集模板](cases/import-case-template.md)，敏感原始单据继续保存在资料提供者控制的位置。
