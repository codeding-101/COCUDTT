# 集装箱账单费用提案设计

2026-10-15，第三十六轮。先提供独立、只读提案 API，不接入运行界面，不写入项目费用，不改变文件版本、金额、责任、税基或推荐。

## 输入与边界

提案明确选择账单行及 `REFERENCE_EXISTING` 或 `CREATE_NEW`，最多50项。已有费用复用账单引用核对；新费用须由调用方完整提供 CostItem、说明与单独人工来源核对。明确当前术语、原币、收费类型/范围、固定原金额、发生原因、合同承担、支付方、经济承担方及海关加计/排除；不从 CIF、费用名或方向生成默认值。来源确认记录仍只是人工快照，不是专业认证。

独立账单支持18位小数，现有成本引擎固定金额会舍入到6位。提案保留原金额，超过6位且含非零尾数时阻断，不能先转浮点、擅自舍入或修改全局 Decimal 精度。`0.000001`可精确进入，`0.0000001`不可；多余零不构成精度损失。尚不处理承运人按箱/逐日/整单舍入。

## 阻断与可复核内容

账单绑定失配、缺条件、来源失效、未完成的重叠检查、联合/分开候选均保留待办。FIXED费用的其他计费参数须明确清理。新费用不可覆盖已有ID、扩大到其他术语、混入替代组/依赖/包含关系/报价内含。已有包含、费用的 included_in_quoted_price、含THC主运输报价及相同/联合/分开收费范围不能忽略；现阶段保守阻断，后续设计有来源的解决记录。

提案快照包括完整项目、完整账单及意图，防止只检查金额而遗漏另一行、包含关系、确认记录或方案变更。重验证重新生成完整提案并比对；输出篡改也不能复用。快照不提供身份认证，也不证明复制文件属于新业务。提案/新费用未知字段、有损JSON、超过10MiB的整体输入或输出明确拒绝，不自动删字段。

账单UI的新建草稿与新行使用随机UUID；冻结时钟或删除再添加不复用编号。导入旧行ID保留。模板固定ID仍是合成样本身份，不是新真实账单身份。

## 后续才启用写入

在项目新版本专用映射字段中保存账单ID/行ID/费用ID与输入快照；旧版本同名扩展不能自动激活。必须先验收配对保存和失配、复制身份、删除/更新策略、候选解决依据、精度/舍入选择、重复点击与迟到应用；写入需基于当时的完整新快照。当前不提供 apply 函数，不声明费用接入完成。
