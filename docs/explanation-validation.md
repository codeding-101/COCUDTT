# 第十轮：费用推理、公式展开与费用/税基图

日期：2026-10-12。承接第九轮运输与保险候选，不合并、不更新公开网站。业务定位仍为中国一般贸易进口、单商品一票；所有案例均为合成测试，尚无真实单据及专业人员验收。

## 交付行为

- 逐项“归属依据”列展示本方案事实，按实际执行顺序列出人工指定、合同、发生原因、术语、特殊条件、节点兜底及未确定分支；上层命中后不把后续层伪装成已执行。术语及特殊事实层记录候选的节点、类别、条件要求与录入值、是否匹配以及最终选择；具体度及同分顺序与原解析器一致。
- 归属与汇总分开：展示本方案报价内含的实际判断、声明清单/费用项标记的选择、父费用、最终去重/未拆分处理、是否计入双方及该项海关计税组成。低可信推断、来源待办和未确认资料不被图表变成“通过核验”。
- 六种计费方式在实际运算处记录替值与结果。阶梯记录各档金额、分档和高档择低候选；依赖图记录已解析百分比基数和真实汇率，不再从界面展示金额重算。日计费仍是录入计费天数×全部箱子合计日费率，不自动处理免费期或箱数。
- 四组可展开公式：完税价格/海关换算、递进进口税额、退税与资金占用、采购成本/利润/买方支付。保留计税免征前后金额和引擎精度；中国税款舍入至分，通用中间数保留6位；消费税只支持现有从价模型。中国进口退税显示“不适用”，未知采购成本不补0；旧出口退税仍明确为简化测算，不能作为可取得退税款的证明。
- 四张文字与颜色并列的横条图：费用明细汇总去向、卖方费用构成、买方总支付构成、海关计税价格构成。图表使用已决计入标记及实际计税组件；DDP卖方税不重复计入买方。未计入项的金额只作核对，不能加到总成本。按各图最大绝对金额缩放，负数标注冲减，不将负数或零合计绘制成占比图；图之间口径不同，不能相加。
- 原生details可用键盘展开，公式组/费用依据展开状态在重算后保留。独立内部HTML复用结果渲染并默认展开所有依据与公式；无远程图表库、脚本或字体依赖。仍不是客户白名单报价或实际PDF文件。

解释来自`src/engine`，`src/ui/result-explanation.ts`只转义与展示；`src/engine/visualization.ts`只聚合已决结果，不复写责任、计费或税务规则。解释记录版本1.0、费用规则1.1、物流核对1.0分别记录。没有增加项目输入字段，JSON继续0.8并读取0.1–0.7，不需要新的文件迁移。

## 依据与边界

本轮展示现有公式，没有扩展国家税制或更改税率和金额。核对海关总署第272号令[第13、17、19条](https://www.mct.gov.cn/preview/whhlyqyzcxxfw/ss/202411/t20241106_956082.html)，分别涉及计征汇率换算与金额舍入、从价/从量/复合关税及递进代征税、税款舍入；小额代征税参考[财政部通知](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/jckss/200606/t285465.html)。模型只支持从价消费税，复杂税种、多商品同票、待遇/归类/抵扣及2026出口退税完整金额条件仍需扩展和专业复核，详见[规则盘点](professional-rules-review.md)。代码执行解释不证明合同、发票或来源内容真实有效。
