# 新手与专业工作台：实施计划与验收边界

2026-10-16更新。根据用户体验反馈，把近期优先级调整为“第一次使用也能完成一笔测算”。专业功能继续保留，费用应用暂排在界面反馈、税务和精度边界之后。本文区分本轮交付与后续目标。

## 第一阶段：信息架构和计算反馈（第四十五轮）

本轮实施默认新手模式及可记住的专业模式。模式偏好独立存储，不进入项目JSON、配对、报告或客户文件；切换不重算业务、不改费用、来源、利润、税款、草稿及文件保存状态。存储不可用时本次切换仍有效并提示。

新手模式从快速入口、交易与商品、报价与方案进入当前测算摘要。核心保留项目名、运输方式、数量/单位、货值/币种、采购成本/币种、术语、报价/币种、比较基准；中国进口仍展示净价口径，不能为减少字段而默认确认净价。商品名称、核算币种、日期、税目、合同事实、商业与海关汇率、进口税务及详细费用放入可展开的高级设置。原数据仍完整参与计算。运费和保险提供一键直达原费用明细，尚未做可能误合并多行费用的快捷金额编辑器。

专业模式展示全部原有交易字段、四种比较基准和完整结果，仍可折叠；导出菜单收纳项目JSON、内部HTML/Excel和客户预览入口。原合同、保险、运输、集装箱、付款及核对记录入口保留。帮助/模板/合成案例放在后方。

金额或数量清空/格式不合法、非正数量、无效目标毛利率、缺少申报日期及非正汇率等可同时列出。错误项可以定位实际字段并展开祖先面板；其他引擎错误保留编码和完整提示，不根据错误文字猜测具体费用。提示层不替代引擎，也不改变未启用数据的计算规则。

输入时标记待更新，隐藏旧KPI及摘要数字，暂停结果导出入口；保存前先提交当前输入；失焦或回车后沿用原计算管线重算。IME输入中的回车不触发。计算成功、参考测算和无法计算分别显示，不把程序检查成功称为法律、税务或真实业务认证。计算是同步过程，本轮不增加虚假的等待动画。

摘要只读取引擎输出：报价收入、承担费用、采购成本、适用的出口退税和退税资金占用；未知成本继续显示无法评估。金额卡片是当前录入报价的结果，固定毛利率/固定买方支付的反推结果明确在方案对比中查看，两者不能混用。完整公式与费用归属直接展开已有真实替值记录，展示层不重新计算。

视觉采用浅灰底、白色输入区、深绿色结果区与细边框，避免渐变、装饰插画和冗余卡片。手机继续吸顶，保留两列紧凑工具按钮与数字键盘提示；先验收折叠路径、键盘和320px布局。十余字段、进口前提和结果不可能在所有手机一屏同时容纳，目标是少量明确步骤，不以隐藏必需事实满足“一屏”。

## 第二阶段：精简编辑、教学解释与移动操作

第四十六轮已交付第1项的保守编辑范围和第3项七类上下文帮助，详见[验收](quick-costs-validation.md)。快捷面板默认收起、不自动选行；只写明确选择、当前活动且无复杂关系的USER固定/实际金额，选择不存入项目。多笔可分别选定，复杂计价、包含/依赖、候选组及集装箱/港费范围只读。已验收输入提交、精度、确认失效、保存重开、弹窗键盘与异常恢复；手机二级页面、教学操作数展开及极端输入说明仍待完成。下列为本阶段完整目标，不将首批交付当作全部完成。

第四十七轮已完成第2项的当前结果教学层：报价/利润、逐笔原币与核算金额、实际汇率解析、汇总去向和海关计税分别展示；可跳转原依据/公式/图表，保留精度、未知与待办，不读取新输入重算旧记录。输入待更新时隐藏旧教学内容，点击入口先提交再重算。新增21项、70文件2397项、31套浏览器及新26项通过，见[本轮验收](calculation-learning-validation.md)。第4项移动端二级操作和第5项极端输入提示仍未完成；下一轮先验证移动交互方案，随后进入第三阶段。

第四十八轮已完成第4项的高级设置范围：700px及以下可进入全屏面板，直接使用同一原表单；返回提交编辑、恢复入口与背景滚动，重绘保留内部滚动，嵌套帮助和错误定位贯通。面板内打开/保存、取消/失败、成功导入退出旧范围、迟到读取、改宽与异常恢复已检查。新增10项、71文件2407项、32套浏览器及新30项通过，见[本轮验收](mobile-settings-validation.md)。本轮覆盖费用/汇率/税务等高级设置，独立账单、配对与付款仍为原面板；未声称全部功能都有二级页面。下一步先明确第5项的精度/支持范围，再进入第三阶段。

第四十九轮已完成第5项的只读提示范围：检查核心数量/金额/单位、当前比较目标、当前术语活动USER费用的实际计费参数及汇率记录。超六位小数、超精度数量级、舍入归零汇率和可疑单位可定位；原文本和计算/排名/确认保持。金额或乘积的处理精度与操作数、卡片展示和中国税款舍入分别说明，不自动换算单位、反转汇率、拒绝负数冲减或任意认定商业日期违法。新增49项、完整72文件2456项、33套浏览器与新25项通过，见[验收](input-review-validation.md)。本阶段约定范围已交付，下一步进入第三阶段首次引导；不将提示称为所有极端输入的准确性或安全保证。

1. 主要运费/保险的快捷编辑：只编辑用户明确选择的既有费用；多行、阶梯、百分比、互斥报价或已含父项必须保留原明细，不自动相加、同步货值/报价、创建默认费用或猜承担方。新增与删除也要有明确范围和失效反馈。
2. 计算过程的教学层：在真实操作数记录上补充每行原币与核算币种、汇率依据和图表指向；区分当前录入报价与目标基准反推方案，不展示由舍入值重新拼出的“公式”。
3. 字段级帮助：比较基准、净价/整价、贸易术语、费用归属、运输变形、税务与来源各给简短解释和适用场景；键盘、触屏和屏幕阅读器均可关闭和返回原字段。
4. 手机二级页面或底部抽屉：先验证焦点限制/返回、未提交输入、滚动恢复、导入导出与错误定位，再选择交互形式；不以大面积CSS隐藏代替状态管理。真实手机仍按用户安排暂缓。
5. 极端金额、错误单位、币种和日期逻辑的友好提示。汇率正数及海关适用期沿用现有规则；商业汇率日期距出口日期较远不自动认定违法或错误，阈值应由明确合同/业务口径决定。极端大数的限制先说明精度及支持范围，再做拒绝或提示，不用JavaScript浮点重新计算。

通过条件：新手完整输入、修错、查看依据、另存、重开一笔交易；专业功能无丢失，金额与原币精度一致；320/390/768/1440宽度和键盘流程通过。涉及规则的新增项另有固定反例与独立手算。
