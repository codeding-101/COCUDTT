# 独立浏览器编解码器与有界任务

2026-10-25，第九十七轮。承接[异步接口契约](fee-browser-recovery-design.md)，本轮实现[浏览器模块](../tools/fee-browser-native-codec.ts)，保留[Node原协议](../tools/fee-layered-capture-prototype.ts)作不改动的字节对照。原生模块没有Node API、源码读取或运行时文本变换，使用TextEncoder及WebCrypto SHA-256。**这是诊断实现，尚未接入正式工具，也不是完整工作台重开器。**

## 相同协议，两种运行环境

沿用分层协议0.1及原kind，没有新业务文件格式。规范保留根与捕获外壳分别顺序编码；完整字符串叶值可以引用，结构容器总是展开。重复持有者保留各自字段，null、空文本、未知历史、未提交输入及非BMP原文分别保留；负零使用原标签。对象自有键、原顺序及`__proto__`等普通数据不会转成执行行为。

浏览器实现有意保留独立协议算法；严格JSON解析和生产语义捕获校验仍调用原模块。它不是独立财税算法，也不绕过原解析器。双实现增加维护成本，所以任何协议改动都必须先通过双方编码完全一致、双向解码与精确再编码，以及坏协议拒绝的门禁。原Node实现、旧测试和七份历史报告保持字节不变。

编码在第一次异步等待前完成借用数据的遍历、完整预算检查和分离。此后原所有者修改不改变已经分离的数据；是否可签发当前观察仍由[原契约](../tools/fee-browser-capture-contract.ts)在每次等待后复核。解码先验证结构、闭包、两根边界及摘要，再物化和核验两份SHA-256，最后深冻结。解码只能恢复数据，不能恢复文件采用、客户确认、候选或费用应用的私有身份。

## 取消与资源占用分别处理

`FeeBrowserNativeCodec`实例的`encode`和`decode`共用一个工作槽，**没有等待队列**。工作中收到同实例请求，立即以固定`BUSY`错误拒绝，在读入借用字段或再次调用加密之前退出。一个工作台必须复用同一个实例；自行创建多个实例仍会拥有多个独立槽，本轮不声称全局限流。

外层契约负责及时拒绝取消、关闭或被新请求取代的观察。若底层加密Promise未结束，原生实例仍保持`WORKING`；直到它实际结束才释放槽。每次加密后检查AbortSignal，已取消时不再开始下一次加密。底层异常和取消原因不读取消息、堆栈或名称；加密失败返回常量代码。

这意味着取消后立即重试可能得到忙碌，不能无声排队。后续正式UI若接入，须明确提示等待任务结束后重试，并区分忙碌、输入超限与业务未就绪；现有接口的`ENCODE_FAILED`/`VERIFY_FAILED`仍是阶段级错误，不能直接冒充详细容量提示。同步JSON校验、物化及TextEncoder工作不能在执行中被JavaScript事件打断，WebCrypto也没有物理取消证明。没有测量提速、冷启动、绘制或峰值内存。

## 原预算保持

| 规则 | 本轮行为 |
|---|---|
| 保留根、完整捕获 | 分别128 MiB；大字符串引用不改变展开预算 |
| 每根语义结构 | 300000节点、根零深度32；重复别名展开计数 |
| 编码文本 | 128 MiB，4096条共享文本、每块512节点 |
| 字符串 | 严格Unicode；中文/非BMP字节与Buffer、TextEncoder一致，孤立代理项拒绝 |
| 其他备份层 | 256/48/64/5 MiB各自含义沿用[上轮说明](fee-browser-recovery-design.md)，本轮不改 |

原1/4/8资料在实际工作台诊断路径重跑。1笔完成还原、原预览和十组候选准备；没有应用费用。4笔完整捕获225,678,795字节、8笔保留根284,281,150字节继续被拒绝，编码、解码、预览和准备均不执行。较小的引用编码不能当作完整业务容量增加。

## 后续第九十八轮

先实现完整恢复格式的独立数据还原器及失败保留验证：版本与解压展开保护、全部原文/历史/未提交状态的覆盖清单、安静状态下的新所有者、已应用费用与回执的保留和防重复。历史异步事实仅作审计；不得复活读取、Promise或令牌，不得自动重放`pending_patches`，不得继承客户确认。恢复失败保持原工作台。

接入仍须完整预览、十组候选、用户明确确认、一次费用/回执、正式文件交接、客户隔离及恢复的真实证据，并说明实际收益；原4/8容量限制在完整成功路径证实之前保留。真实手机、实际单据和人工专业复核继续按用户安排暂缓。见[本轮验收](fee-browser-native-validation.md)。
