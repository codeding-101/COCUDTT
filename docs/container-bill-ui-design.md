# 集装箱账单界面接入：第三十五轮

2026-10-14。接入已验收的独立账单1.0文件和只读核对层，原日历日计算边界不扩充。本轮交付结构化录入、独立打开/另存、来源确认、逐日审计、内部HTML/Excel和恢复；不写项目费用、承担、税基或推荐。

账单在单独面板与本地草稿键保存；项目JSON不嵌入账单。打开/新建项目保留账单输入并撤销失效费用引用，不自动重新绑定；显式重新绑定保留原输入、撤销相关确认。刷新可恢复独立草稿，读取坏草稿先提示，不在启动时覆盖原文。自动草稿失败提示单独保存，不把文件下载发起当已落盘。

字段控制允许未确认项，不预置币种、日期、费率、免费期或端点。不支持的原选项作为原值显示，编辑其他项不丢失；切换计费模式只改模式，旧不适用字段必须由明确“清除其他模式字段”操作移除，不静默覆盖。逐日审计最多预览30天，内部Excel保留全部、原输入快照和来源/待办；最多50行/50箱/20阶及已验收大小上限保持。大量日期不默认展开到页面。

人工核对使用明确确认按钮，来源文本/适用期/核对日先录入；EXAMPLE保持示例，用户明确改为待核对再确认。条件或来源变化调用克隆失效函数；不把来源通过变成整体业务合规。有不可计算行时显示重叠核对范围不完整；联合/分开候选及已有包含/重复费用引用继续保留。

保存、报告和资源内容在选择器前固定；保存过程中允许编辑但只保存先前快照。读取使用世代计数，编辑/项目变化/另一次读取/界面异常后迟到读取不覆盖当前输入。取消/读写失败保留输入，底层错误/路径不回显。异常恢复原始备份包含账单和独立草稿原文；只读检查可识别新可选部分，旧恢复文件六部分检查保持，不自动导入或重确认。整体备份仍受原5MiB检查上限；超限原文用于人工复原。

客户公开白名单不读取账单/内部引用/来源或草稿。本轮不新增客户账单输出，不将内部资料复制为报价条件。内部HTML/Excel有独立账单快照和参考结果，含完整内部资料，提示勿发客户；费用写入由下一阶段单独提案和验收。

验收：真实界面事件/文件冻结和竞态、浏览器离线实际下载、来源失效/重绑/已含引用/不支持输入、客户隔离、异常备份/重试/草稿恢复/只读检查；1440/768/390/320模拟宽度及全部既有离线流程回归。真实手机、专业与实际单据验收按既定安排暂缓。
