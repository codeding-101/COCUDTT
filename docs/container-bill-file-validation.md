# 集装箱账单文件与只读引用验收

第三十四轮，2026-10-14。本轮按接入计划先交付文件/核对层，[设计](container-bill-file-design.md)在实现前明确；运行工具控件和费用写入属于后续阶段。公开网站保持，验收源码和README按既有授权更新main。

## 交付与边界

独立INTERNAL_CONTAINER_BILL JSON 1.0、Draft-07 Schema、空白与固定合成两份模板均从源码重建。旧项目0.8/0.9、付款1.5、恢复1.0和独立计算0.1保持；文件不能互相误读。未支持模式、缺字段、空/null和坏数值文本可留草稿，结构正确不等于可计算；原日历日API仍只接受完整支持条件。

未知语义仅在extensions保留，不激活同名来源/金额/版本字段。JSON序列化先检查有损值、访问器和大小；扩展8层/10000节点/256KiB UTF-8，整个文件5MiB UTF-8/32层/200000节点。字符计数与Schema一致，跨行唯一ID及字节/深度边界另由运行时核对。解析返回新值，不修改项目、不自动重确认。候选仅检查可计算行；有坏行时明确报范围不完整，不能将空候选当全部排重。

逐行来源快照覆盖账单原条件、草稿ID、核对日和绑定；EXAMPLE不能由确认函数直接升级。数据、来源及绑定变化发现旧快照并由克隆失效函数撤确认。已有费用引用的来源另核；未提供当前项目时引用继续待核对。绑定是原始事实快照，不是唯一项目身份或认证签名。

只读引用核对存在/唯一/当前术语活跃、原币/明确类型及范围、原币FIXED金额文本和来源；不使用六位量化或数字输入冒充精确匹配。不匹配、非FIXED、同费用多行引用、已有包含/报价内含及主运费THC包含均有待办。确认不插入/改写费用或消除联合/分开候选，不改变承担、风险、完税价格、利润或推荐。

## 验证

新增129项、完整56文件1693项通过，核心证据包括：

- Schema严格Ajv编译及生成一致性，两份模板复建/回读/副本隔离；空模板无业务默认，固定合成例题每箱120/两箱240 USD、来源仍EXAMPLE。
- 未支持工作日/按票、空/null、坏数值草稿保持；混合完整/坏行只有完整行参考金额，原计算API整份坏输入拒绝。Unicode、18位费率、公式样文本、扩展同名字段/原型键不执行或激活。
- 结构错误/未来版本/别类容器、重复ID、字符/行/箱/阶上限；NaN/Infinity/BigInt/undefined/函数、稀疏/循环/Date、访问器/符号/隐藏属性及额外数组属性拒绝。扩展深度/节点/UTF-8、整体大小与不可回读快照集合拒绝。
- 冻结输入及返回副本隔离；来源/业务条件变更、过期/错误核对、绑定变更、明确重新绑定、备注/扩展与其他行隔离；合成确认测试只验证软件状态，不是业务认证。
- 已有FIXED原币精确文本，低全局Decimal精度不遮盖18位差额；数字原金额待核对。引用不存在/重复/未活跃、缺说明、不同币种/类型/范围/金额、非FIXED、包含/报价内含、同费用多行和未绑定不能确认引用。
- 费用承担/合同覆盖/包含/THC包含等改变使引用失效；原包含事实与联合/分开候选保留。项目保存及成本/风险/税务分析在只读操作前后保持，旧业务全量回归通过。
