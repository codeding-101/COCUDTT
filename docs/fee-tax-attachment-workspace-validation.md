# 费用与税务成分工作区验收（第六十二轮）

2026-10-17。承接[独立交接模块](fee-tax-attachment-controller-validation.md)，本轮把已验证文件/数值模块接入“高级设置 → 费用与税务成分 · 独立内部假设”。默认折叠，手机使用已有高级设置全屏面板。附件是独立的内部假设资料，不是费用应用、税务资格认证或海关申报结果。

## 操作路径与领域边界

1. 在“项目＋账单配对交接”准备项目与账单，并捕获完整当前修订；若项目/账单失配、提案编辑尚未提交或主输入待计算，不能作为当前附件来源。
2. 从当前配对新建空附件，明确确认替换本面板资料；新增记录时明确选择映射，再自行填写金额/币种或点击“明确取用该行原币金额与币种”。不会自动套用税率、金额、来源或资格。
3. 逐项记录金额拆税、抵扣假设和海关成分。税率填比例，未知保持未知，不换汇、不合计不同币种；展示G/N/T/X/E/C的精确整数/分数和原始推导。E不是经营利润，C不由N或E推定。
4. 完整提交后再分别记录三项来源确认。来源/金额/映射/当前业务未满足条件时保留待办。修改任何输入或来源撤销该记录三项确认；完整配对变化后须明确捕获并重新绑定，撤销全部确认。孤立目标保留待处理。
5. 切换一个处理分支会清空该分支专属字段，表单有明确提示；其他成分及来源保留。不支持或结构不完整的恢复文本按原文保留，不静默投影成空表单。

新建、删除、重新绑定、放弃编辑和放弃本机槽位有界面内明确确认，并绑定当前附件/编辑/完整业务来源。确认期间资料变化则不执行替换。附件JSON先校验为候选，明确采用只替换附件面板，不安装其中的项目/账单。

## 草稿、导出与异常

- 两个独立浏览器槽位按[控制器契约](../src/ui/fee-tax-attachment-controller.ts)保存附件与未提交编辑。启动不自动覆盖或恢复。明确检查和恢复、其他标签页冲突保护、原文备份、完整内存备份及槽位CAS放弃/重新保存均可操作。
- 未提交编辑不进入JSON/HTML/Excel成品。另存或导出冻结点击时已提交数据；后续编辑不改变生成中的快照。下载回退只报告已发起下载，仍提示确认落盘。
- HTML/Excel包含完整内部来源与附件JSON；Excel金额使用精确文本而非二进制浮点，不截断原文，超过8MiB限制拒绝并提示改用JSON。客户报价导出继续使用原有公开字段投影。
- UI异常恢复备份可保留附件内存、编辑与两个槽位原文，不运行税务计算；这些附件项在通用恢复检查器中作为未知扩展保留，不能据此声称已通过附件格式校验。独立内存备份也是人工恢复资料包，不可直接作为附件JSON导入。
- 两个槽位不承诺原子写入或跨进程锁；部分失败时保留内存和旧原文，并提示备份。文件指纹不是签名或真实订单认证。
