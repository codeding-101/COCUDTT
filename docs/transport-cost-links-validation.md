# 运输费用关联独立模块验证

第三十一轮，2026-10-14；设计见[边界与接入设计](transport-cost-links-design.md)。新增独立领域类型、结构检查、引用/来源核对及重叠候选，不接入UI、分析/比较入口、项目/恢复文件或内部/客户导出。

## 已实现与边界

人工明确核对范围，按方案复用costsForTerm；关联稳定费用/运输段ID，原路线连续选段，不按名称、节点或金额自动补范围。UNCONFIRMED、LINKED与有依据的NOT_APPLICABLE分开。缺失/重复/逆序/不连续引用、所选段衔接错误和来源问题分别记录。

来源沿SourceEvidence/checkSource核验，快照覆盖成本输入、运输/交货事实、当前/原合同报价、术语、比较日期及关联字段。改变相关输入后原确认不再通过，函数不重写确认。派生成本不作为新事实输入。

同收费类型+完全相同的人工scope_id+段交集产生候选，记录原直接/共同父包含关系，不扣费、不分摊或新增去重。不同类型/范围无候选也不证明绝无重复，跨类别包含继续核对现有合同。未关联段不当费用缺失或免费；reference_checks_passed仅为引用/来源检查，review_required还包含重叠候选，两者不等于业务合规或推荐资格。

## 自动化证据

新增67项、完整53文件1388项；以下多轮对照另作为测试内部案例，不加到测试总数：

- 陆海陆通运引用三段，保持一笔金额、唯一风险点和运费支付终点；空核对范围不视为通过。
- 待填/不适用、13类业务引用问题、7类来源问题、14类输入修改导致快照失效。
- 不活跃费用的失效引用暂不参与当前方案，再启用重新核对；互斥组及已有依赖检查沿用原实现。
- 直接包含、共同父费用、无包含关系均保留候选；不同类型/范围/不相交及36组独立集合交集对照。
- 16类坏结构拒绝；100费用×100段及4950对候选上限；冻结输入与输出段数组隔离。
- 调用前后原analyze/compare完整结果、风险、税费和项目保存字节一致；旧同名扩展保留且不解释。

严格类型、绑定审查、单文件/目录构建、依赖审计及设计14手算/16错误检查单独核对。Windows/Linux CI按最终实际提交核对完整测试及跟踪产物重建一致性。

本轮运行工具、旧业务算法、项目/付款/恢复格式、Schema、模板/12份配套资源、依赖和UI源码保持；单文件工具重建后须与前轮相同。原22套浏览器流程为第三十轮历史证据，本轮不将其计作重跑通过；独立模块尚未进入浏览器运行路径，因此本轮针对函数、旧业务不变和构建做验证。产品介绍/README仅同步状态与后续目标。
