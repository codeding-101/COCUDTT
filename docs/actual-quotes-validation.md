# 独立合同报价与费用约定验收（第八轮）

此前运价可以逐术语启用，合同报价仍共用一个金额，界面没有合同费用覆盖入口。本轮新增“实际报价：各方案独立录入”，保持原来三种模拟比较基准。开发候选继续保留，不合并、不更新公开网站。

## 输入与计算范围

- 逐术语保存金额、币种、商业汇率类型与日期、指定地点或港口、报价来源、有效期及人工核对快照。未录入报价不计算该列，不套用公共金额；一列金额或汇率无效时，其他列继续计算。
- 合同比较日期显式录入并随项目保存。报价与合同费用约定按此日期检查有效期，包含首尾日期；税率及海关汇率仍按进口申报日期核对。可复现历史测算，不用电脑今天的日期悄悄重写历史结论。
- 每个术语、每笔费用可指定卖方或买方承担，记录条款说明和来源有效期。该约定只影响相应术语；费用承担改变不改变风险转移规则。分摊须先拆为两笔，实际代付和追偿现金流尚未建模。
- 待核对、过期、指定地点缺失或报价构成无法与货物净价及已含费用勾稽的实际报价保留参考金额，不参加确定排名。人工核对不是认证；金额、商品、交货事实或来源变更后旧快照失效。
- 各方案共用同一商品范围及货物净价。若供应商报价包含不同净价、商品范围、数量或其他估价条件，应分项目测算；不根据整价倒猜海关货物净价。CIF/CIP保险费用存在不证明险别或保额满足要求。
- 切换模拟基准不删除实际报价及核对记录，但本次模拟使用公共金额或目标反推；逐术语的合同费用约定仍应用。

## 文件与报告

标准JSON格式升级为0.7，新增`evaluation_date`、`term_scenarios`及`ACTUAL_QUOTES`基准。每个术语记录含可选`quote`、`quote_evidence`、`responsibility_overrides`。不完整报价仍能存为草稿；错误结构或未知术语明确拒绝。

读取0.1–0.6文件不生成实际报价、核对状态或合同费用约定，不自动改变税务模式；保存使用0.7，旧程序应拒绝新格式。保留数值原始表示及未知扩展字段。界面删除费用时一并清除对应约定；导入文件若约定引用不存在费用，显示待办及删除入口，不静默应用。

内部HTML报告记录生成时的实际报价、地点、比较日期、费用说明、来源与待办，嵌入不可变完整项目快照。它仍包含内部信息，不是客户报价单，也未实现原生PDF或Excel导出。

## 合成案例与工程证据

单商品净价10,000 CNY，卖方主运费600、买方主运费1,000（二选一），保险费100；合成从价关税5%、VAT13%，不抵扣。示例人工核对全部是测试资料，不是真实交易或官方认证。

| 项目 | FOB实际报价 | CIF实际报价 |
|---|---:|---:|
| 合同报价 | 10,000.00 | 10,700.00 |
| 海关完税价格 | 11,100.00 | 10,700.00 |
| 关税 | 555.00 | 535.00 |
| 进口VAT | 1,515.15 | 1,460.55 |
| 买方总支付 | 13,170.15 | 12,695.55 |

卖方采购成本未知，利润保持未知；共同净价与不同运价解释差额，不用同一合同金额代替两份报价。仅报价核对及其他业务条件齐全的列参加排名。

本地完整测试30个文件、508项通过，其中新增25项覆盖独立币种/汇率日期、有效期首尾及超期、非法/空/零/负报价、缺失报价无回退、快照失效、净价勾稽、费用约定作用范围、旧文件和报告转义。TypeScript、静态审查、Vite与离线构建通过；静态审查新增合同字段，发现问题时返回失败状态。

Edge自动验收：实际报价录入、缺失列不影响其他列、过期排除、修改确认失效、FOB港杂费约定、切换模拟与实际基准、0.7保存及File/DataTransfer重开、内部报告均通过；1440/390/320px无横向溢出，未处理异常为零。既有中国进口和专业规则两套浏览器验收也通过。保存API使用内容捕获替身；真实磁盘下载、打印分页、iOS/Android设备仍待验收。

远程Windows/Linux CI须对应本轮提交，结果以草稿PR检查为准；本地检查不代替远程记录。前一专业规则轮483项CI属于PR #4，不能写成本轮508项CI。
