# 移动端高级设置的异常恢复

2026-11-04，第125轮，本地开发候选。沿用原生dialog和同一棵表单，修复上轮复现的六项故障：滚动优先级丢失、覆盖外来滚动样式、占位丢失后表单隐藏、缺少宿主仍报告打开、原生打开异常和关闭异常。

## 原节点与明确重试

[移动面板控制器](../src/ui/mobile-settings.ts)保存实际dialog、宿主、表单、原父节点、下一兄弟及自建占位引用。归位先使用仍在原父节点中的自建占位；失效时使用原父节点与仍有效的兄弟；父节点已移除时，放到dialog外或页面body，保留原控件和File对象。不替换或移除外部提供的同名占位。

打开前核对实际连接的dialog、宿主和表单。原生打开失败或没有真正打开时，归位表单、撤销仍由本面板持有的滚动设置，并给出页面内提示。应用入口继续使用原页面回退，预期打开失败不再触发整页恢复。

关闭先等待原生dialog的实际状态。抛错或不执行关闭时，保持打开状态、原表单和可见的返回按钮；用户修复原因后明确重试。若原生关闭已经完成才抛错，则继续归位。关闭事件只处理当前实例，并隔离同步关闭回调和旧实例的迟到事件。

原生关闭可能同步触发输入失焦及整页重绘。关闭期间的重绘不重新打开替代弹窗；只有旧树已被实际替换才退役旧节点，关闭完成后也不把已退役的旧表单插回新页面。保留实际仍连接且打开的失败弹窗，明确重试；已断开的旧弹窗不冒充仍需关闭的新视图。

## 文件扫描前的保全

宿主被移除后，再次打开或重绘可能使File节点脱离渲染器扫描。重绘前先归位已知的脱离表单；原生关闭失败时，先重接已知且无父节点的原宿主，保证File仍在可扫描的原页面树内。全局重绘继续由[原文件节点保全](../src/ui/file-input-retention.ts)转移选择，不缓存或序列化File。

明确切换项目仍不继承旧文件选择。若旧弹窗不能关闭，只在新项目渲染实际断开旧树后退役旧视图，不以尚未发生的断开作为完成依据。它不授予完整工作台切换、保存确认或客户批准。

## 滚动样式的有限所有权

分别保存overflow-x和overflow-y的原值与优先级，保留原本缺失的情况。结束时只撤销当前仍为本面板设置的hidden、且无优先级的轴；已变为其他值或优先级的轴保持，未变的另一轴仍可独立恢复。其他样式不清空，后续挂载也不重新覆盖已出现的外来值。

这不是完整样式修改来源追踪：外部写入完全相同的值和优先级，或发生同值往返，仍无法识别。不承诺任意DOM操作发生部分修改后又抛错时都能原子回滚；原应用整体解绑、独立安装和完整工作台切换仍单独验收。
