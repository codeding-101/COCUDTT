# 第十二轮：运费、汇率与费用承担假设分析

日期：2026-10-12。承接基础概念候选；不合并、不更新公开网站。中国一般贸易进口、单商品一票仍是主范围，案例均为合成测试。

## 交付与输入口径

结果下方增加“假设分析”入口，默认关闭。选择当前术语下的一笔运输费用、一行商业/海关汇率，或一笔承担未确定/未分摊费用。数值输入起始/结束变化及步长，区间须整除，最多21点；基准始终独立显示。界面每次只分析当前选中的术语，切换术语后核对对象；引擎可接受多方案输入。

- 运费按原币金额或费率缩放：固定/实际金额、数量单价、百分比、日费率、阶梯各档费率；数量、天数、边界及高档择低保持。依赖费用、适用术语、互斥组、报价去重、税基和税额通过原引擎重算。退款/负运费不纳入本项涨跌，-100%可归零。
- 汇率只改所选表的币种对，不改其他类型/行、不联动反向报价、不替换显式汇率；仍按原优先级解析。汇率不能归零或负值，量化后为零的点明确失败。实际申报日期、有效期保持，不把假设海关汇率当官方申报汇率。
- 费用承担一次只假设该项全归卖方/买方，其他待办保持；不解析共担比例。新入口通过完整比较、报价内含推导及来源核验；旧`conditionalSensitivity`接口保留兼容，不用它绕过新管线。
- 保留当前比较锚点：实际报价/固定报价不自动改原币价格；固定买方总支付/目标利润率继续通过现有求解器反解，并展示报价变化。实际报价不勾稽、来源快照变动及资格缺失继续显示。

呈现报价、卖方利润、买方总支付、抵扣后成本、进口税额（双方合计）及完税价格，列金额、与基准的有符号差额和百分比。百分比分母为基准绝对值；零/未知不算百分比，未知利润不补0。失败点/方案显示原因与空值，不拿旧金额填充。非零数值和承担情景始终标为假设参考，不加入原项目确定推荐；通过当前检查也不证明合同真实。

## 数据与报告

`src/engine/sensitivity.ts`复制领域输入后复用比较管线，保留来源内容及快照、不伪造确认。精确0%直接复用基准，避免重新量化输入造成假变化。原项目、草稿、费用、汇率、报价、确认及保存状态不因参数编辑变化；真正编辑项目时自动重算假设，不沿用旧结果。

参数属于本页临时状态，不写入项目JSON；新建/打开项目重置。内部HTML报告保存生成时的参数及结果，参数无效时保存明确错误和参数；报告无脚本/表单控件、用户文本转义。项目仍0.8，费用规则1.2、物流/解释1.0，假设分析记录1.0。本轮未扩展或更改海关/税务公式。内部报告含完整输入，不能当客户白名单报价。
