# 第五十二轮：客户报价简洁版与完整版

2026-10-16。客户预览新增版式切换，HTML、Excel和本机PDF跟随选择。完整版保持默认；简洁版减少留白，不删减公开内容、不保证一页完成，也不缩小PDF正文字号。中英文条款摘要仍为独立固定格式。

## 内容与状态边界

两版都从原客户公开字段投影生成，保留15行交易/公开条款、风险转移、保险与税费责任提示、有效期、全部待确认事项及免责声明。原币金额保留录入精度，不生成单价、税额或承诺。采购成本、利润、内部来源、完整项目及内部计算假设摘要均不进入客户文件。

版式仅在当前页面内存中保留，不进入项目JSON、配对、浏览器业务草稿或恢复文件；新建、打开项目或安装配对时重置为完整版。切换实际版式撤销旧“已检查”，再次选择相同版式不撤销有效核对。公开文字输入时立即撤销核对并暂停导出；未失焦直接切换或勾选核对，会先提交文字，防止复选框事件覆盖未提交输入。

每次导出在文件选择/异步生成前捕获公开报价、版式和建议文件名。等待期间切换版式不会混入旧文件，也不会确认新视图。简洁版文件名增加“简洁版”；Excel仅改变表名及行距，公开单元格一致（独立导出各保留实际生成时间）。默认行距及内部工作簿行为保持。

PDF继续使用本地审阅字体、固定10.5pt正文及自动续页；简洁版缩小行距与内边距。长行重复表头/续行标签，待办和免责声明保留。不支持的字符提示并停止写盘，原文仍可通过HTML或Excel导出。
