# 集装箱账单草稿1.0：格式、确认与只读费用引用

第三十四轮，2026-10-14。[上轮日历日计算边界](container-bill-design.md)保持。此次先完成录入接入的文件/核对层；不增加运行工具控件、不写项目费用，不把参考金额提升为推荐。

## 三层分开

1. INTERNAL_CONTAINER_BILL独立JSON **1.0**：保存空白、缺条件和不支持的计费口径，可继续人工编辑；不是项目0.8/0.9、付款1.5或恢复文件。金额/费率只存字符串，免费日数/阶梯界点为整数或null，端点计入为布尔或null；null/缺失不是零。行line_id须唯一稳定、非空且非原型保留名，最多50行；每行最多50箱和20阶。
2. 日历日计算API仍 **0.1**：仅完整受支持条件可计算。草稿字符串保留WORKING_DAYS等原口径，核对层不转换成CALENDAR_DAYS；一行不完整时该行没有金额，其余完整行仅有独立参考审计，无跨行总额。原计算API任一坏行仍整份拒绝，语义不变。
3. 来源与费用引用：USER_CONFIRMED加快照只表示人工记录与当前条件一致；不证明账单真实、税务/合同合规或已计入费用。只读引用不插入或修改CostItem，不去重、不改承担、税基、风险和排名。

## 文件与扩展

根字段kind/version/id/name/review_date/binding/notes/rows必需，extensions可选。每行input必需，evidence、cost_reference可选。input只允许已知账单字段，但其草稿条件可空/缺失/未支持；period/daily可null，已出现的内部字段仍须正确类型。rate文本最多200字符，ID/选择字段最多200，reference/备注4000，来源快照最多1,048,576字符；草稿按Unicode字符计数，计算API沿原上限独立核验。默认不补日期、币种、费率、免费天数或计入端点。

未知语义只能存于显式extensions对象，按解析后的JSON值保留且不参与计算、确认或绑定。扩展限JSON原始值/有限数字、深度8、10000节点及256 KiB UTF-8；整文件最多5 MiB UTF-8、深度32及200000节点。循环、undefined、函数、BigInt、非有限数字、稀疏数组、访问器/符号属性和非普通对象拒绝；序列化不能静默将NaN变null或将非JSON值丢掉。未来版本/别类容器和未知活动字段拒绝，不自动升级或解释重名扩展。

提供Draft-07独立Schema及空草稿/合成完整两份模板，均从源码重建，旧Schema和模板原值保持。Schema检查形状；跨行唯一ID、扩展深度/节点/字节、整文件字节和业务检查由运行时另核。导入只返回新值，不替换当前项目；取消/竞态/本地恢复和真实下载仍在界面阶段验收。

## 来源与失效

每行复用SourceEvidence。快照包括草稿id、绑定、review_date及原input；源引用、适用期、核对日也由既有evidenceKey覆盖。确认操作要求该行可计算且来源核对无问题；EXAMPLE保留为示例，确认函数不将示例变真实。核对当前日期须明确且有效，来源有效期覆盖该日期。

解析保留原确认记录以供审计，核对时发现旧快照/过期记录；不会自动“重新确认”。编辑函数克隆输入，条件/草稿id/绑定/核对日变更使相应确认撤为UNVERIFIED，原快照可供复查；仅备注或extensions改变不替代账单条件。来源文字/适用期/核对日修改同样失效。费用引用确认单独检查，不因账单来源通过而自动通过；调用失效函数而未提供当前项目时，已有费用引用保守撤为待核对，不能证明成本现状未变。

## 绑定与已有费用引用

binding可null，表示独立账单；显式绑定才记录当前术语及原始项目事实的稳定快照。涵盖项目名称、商品名称/数量/单位、路线/运输方式、比较基准、当前报价/指定地点、原运输计划和比较日期；不从模拟价格推定实际账单。快照不是全局项目ID或签名，两个事实完全相同的项目仍可能相同，写入时须再次由用户选定项目。

cost_reference只引用**已有**cost_id，含人工note及独立evidence。核对当前绑定、成本ID唯一/存在/当前术语活跃、币种、显式集装箱类型/范围及来源快照；同一费用被多行引用列待办，不用后一行覆盖前一行。仅已有FIXED原币**金额文本**做精确数值对照，数字输入和其余计价方式标明需人工金额核对，不采用派生/六位量化金额冒充原账单金额。

记录contained_in_cost_id和报价内含情况，有包含关系仍需复核；原包含引擎独立处理。不同scope、来源、费用名不证明没有重复；联合/分开候选一直保留。候选仅在可计算行之间检查，有未计算行时另报OVERLAP_SCOPE_INCOMPLETE，空候选不表示完整排除重复。引用检查没有“费用已计入/可写入/可推荐”的通过标志，引用有效也不自动修改成本。费用币种/金额/范围/承担/包含、商品/报价/运输/方案变化会使引用快照失效；删除费用保留坏引用供修正。
