# 独立敏感性与客户公开字段

2026-11-01，第112轮，本地原型。复用原敏感性分析、公开报价投影与HTML/Excel/PDF导出器，保存当前输入，不把假设结果或旧客户核对当真实业务事实。

独立内部表单1.0分别保存六项敏感性控制、十一项公开字段和客户版式；严格字段、布尔类型和4000字符限制，文件上限4 MiB。财税、项目及标准付款格式保持。完整内部载体显式启用0.2增加表单文件，旧0.1继续读取和按原格式写出；旧读者拒绝0.2，不静默丢字段或升级。0.2父链中的表单不能在子文件中删除，未改输入可重用原文。

客户公开投影从零构建，只取原白名单。核对身份、版式、当前业务/付款上下文与表单修订绑定，仅在当前会话有效；编辑、取消、迟到或重开会失效。客户下载不清除内部未保存状态，不批准合同或履约。

64 MiB编码体、256 MiB累计展开、16层及旧恢复保护保持；所有表单原文计入预算。新字段可使大资料再次交接受限，拒绝时保留输入和分项文件，不截断原始档案、历史或备份。客户与内部资料隔离、版本兼容及结果见[验收](fee-trade-forms-validation.md)、[用例](../tests/fee-trade-forms.test.ts)与[阶段计划](development-stages.md)。

## 输入、假设与事实

| 内容 | 保存方式 | 业务含义 |
|---|---|---|
| 启用、变量类型、对象、起止变化与步长 | 六项控制原文 | 情景假设；不修改实际运费、汇率行或费用承担事实 |
| 客户十一项公开字段 | 用户独立填写的文字 | 仅作为客户草稿公开内容；不从内部付款计划自动生成承诺 |
| 完整版／简洁版 | 明确版式枚举 | 版式改变后重新核对，简洁版不省略原投影要求保留的风险或待办 |
| 敏感性结果、客户预览 | 打开后用当前资料重新计算 | 不作为文件内可信结果，不补造确认或来源 |
| 客户核对与导出身份 | 仅当前会话内对象 | 不序列化、不继承、不用旧文件或复制对象恢复权限 |

运费变化沿原模型按选定费用计算，不改变货物数量或费用计量方式；汇率变化只调整选中行，商业与海关口径保持独立，未被实际使用的行可以没有金额影响。待确认责任分析分别假设卖方或买方承担，不把所有其他待确认费用同时确认。固定报价、实际合同报价及目标基准仍由原敏感性引擎解释；基准为零时差额可计算，百分比不适用，不能以零除制造收益率。

客户报价、付款计划净收付、资金成本和卖方利润是不同口径。本节不将银行费或资金成本扣入贸易利润，不改变完税价格、税率、抵扣资格或税基。客户草稿继续保留原贸易术语、指定地点、报价有效期、标准风险提示及未完成待办；使用者的公开文字不能自动消除原待办或代表已签约、到账及履约确认。

## 提交与交付

敏感性和客户字段共用一份本节草稿；失焦、回车或明确提交均提交当前整份缓冲，长文字使用Ctrl+Enter。输入期间隐藏旧结果，业务或付款缓冲未完成时同样不展示旧客户预览。改变表单、报价、业务或付款上下文会撤销旧核对和完整交接候选，改回原值也不恢复旧身份。聚焦下一字段时不替换该输入节点，避免自然失焦提交后丢失焦点。

客户HTML、Excel与PDF生成器只接受原公开报价投影，不接受完整项目、银行费计划、资金假设、来源历史或恢复档案。每个客户任务绑定当前核对、版式和修订；生成前后与写入返回后均检查身份。取消会立即撤销逻辑权限，仍占用任务槽直到实际工作结束，迟到结果不清除内部修改。已经交给浏览器的下载不能被撤回；“下载已发起”不表示磁盘保存完成。

完整内部下载包含已提交的表单原文；分项表单、付款和客户下载都不能替代完整内部交接。只有与当前全部资料匹配的完整回执，经用户确认文件确已保存后才清除相应内部待保存状态。旧档案中的客户文字与批准只存档，不自动装入本节。

## 本轮边界

本节只在明确启用的独立会话中使用，原工作台与财税、贸易规则保持。完整工作台生命周期、全部未绑定订阅、原生关闭保护、正式入口接入、高级资金版本编辑及多次费用应用分别后置。浏览器窄屏验证不等于真实手机验收，合成数据与导出隔离检查不等于专业贸易或合规认证。
