# 完整检查失败后的源文件指引验收

第九十三轮，2026-10-23。本轮修正失败后的操作建议：整批检查与整份工作台备份可能在同一保护层拒绝，用户应保持页面开启，按需分别另存当前可导出的源文件。[设计](fee-save-guidance-design.md)、[专项测试](../tests/fee-workbench-save-guidance.test.ts)、[实际页面驱动](../tools/check-fee-save-guidance-browser.mjs)及[本轮完整证据](cases/fee-save-guidance-native.json)分别记录范围。

## 可见改动

- 完整检查未完成时说明本次检查没有应用费用，原资料保持，整份检查备份也可能无法生成。
- 备份捕获/编码失败时，明确“检查备份未生成”；不再把提示写到远离操作按钮的通用导出区域。
- 原生取消、保存器异常、未知返回值分别显示取消或保存未确认。保存未确认不能断言目标文件没写过字节，须先核对目标文件。
- 六个按钮只定位原项目、账单、配对、成分附件、精度选择、封套另存入口，不执行保存或确认。320px下仍为两列、有效目标高度至少44px。
- 另存等待期间的取消、资料变更和A→B→A使旧完成失效；迟到成功/失败不能覆盖当前提示。检查备份不更新六类文件的保存证据或客户确认。

**六类JSON不等于完整工作台备份，不包含全部未提交状态。**资料缺失、无效或待提交时，原另存入口可能不可用；仍须保持页面并自行记录需要保留的输入。下载发起、打开证据、已另存和实际磁盘状态分别说明。

## 软件和实际页面验证

新增27项，完整132文件4720项测试通过。覆盖原严格复制拒绝超深状态、编码失败、原生/普通AbortError、未知保存返回值、保存异常脱敏、重复点击、迟到成功/取消/失败、ABA、显式重试、恢复阻断及固定导航。原所有者仍因界面操作推进修订，不能把“原财务资料保持”写成“全部运行状态不变”。

正式离线页面的1/4/8笔合成资料使用原夹具及原打开/采用/预览/另存按钮，不注入生产观察桥。按第九十二轮相同的检查前保存状态，只预先另存项目和封套，再运行完整检查及备份；之后六类正式源文件全部另存，与明确采用的夹具原文逐份核对字节和SHA-256，共24次正式另存。1笔另行验证取消、写入异常、重复点击、迟到保存和重试后的完整原备份。4/8笔仍被原保护拒绝，备份写入器调用0次，不出现可应用候选或确认。

15项页面断言全部通过；4/8两组各在1440/768/390/320模拟宽度检查，8组布局无横向溢出，六类导航都将焦点送到原控件且不调用保存器。源文件原文、已有费用/回执及客户确认保持。保存器和文件输入为API替身；不是实际磁盘、真实手机或真实业务验收。

首次测试采用更重的“先另存全部六类文件”组合，且通过调试接口搬运大文件原文，在8笔阶段发生页面超时；失败记录保留于本地，不计入通过数。最终驱动对源文件在浏览器内就地核对哈希，并恢复同条件的主验证；随后只改变该驱动的案例数/保存顺序，单独重验8笔、先另存六类文件的组合：6项页面断言、4组布局和12次正式另存通过，结果单列在机器证据。正式运行代码在这些试测之间保持相同。不据此断定首次超时的唯一原因，不从一次超时或重试推导性能/容量改善。

本轮对新离线产物重新执行原46套浏览器流程，并重新运行42个复杂状态与27个运行状态的独立历史捕获对照。费用/回执一次提交、防重复、最新代次重准备、提交后恢复、正式文件交接、客户隔离及窄屏均以本轮实际报告为发布门槛，不把第九十一轮同字节证据当作新产物重跑。

普通完整回归与压力资料应使用独立测试状态。首次共用合成缓存时，恢复测试的备份达到9,328,914字节，原5 MiB只读检查正确拒绝；该次未算作完整通过。仅清空专用测试配置的合成缓存后，原46套重新从头执行；45套通过后测试进程中断，恢复专用环境，使用原脚本补齐最后一套报价交接。原恢复上限和全部断言保持。失败、中断与后续完整记录分别保留，不用放宽保护来处理测试状态串扰。
