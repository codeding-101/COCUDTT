# 真实工作台状态与资源观测

2026-11-01，第114轮，本地只读诊断。复用原15组192字段盘点，在真实工作台中临时观测五个未绑定控制器的32字段及40方法入口。原财税/贸易模型、源文件和离线产物不改；工具仅在专用本机诊断页面启用，不替换项目、不授权切换。

实例适配器暂时安装可恢复的属性描述符及方法入口，字段值、对象身份、方法接收方、返回值、Promise身份和原错误保持。普通赋值及登记方法入口推进单调代次，先改后改回仍使旧检查失效；通知只含持有者与代次，不含业务值。安装前核对完整计划，重复实例、访问器、只读字段或方法缺失拒绝。撤销时恢复当前值和原描述符，不回滚操作、不覆盖后来出现的外来描述符；检查器和订阅一并失效。

源码解析生成23处资源调用计划，仅在Vite本机响应中插入局部调用适配，不全局改写EventTarget或URL原型，不写原源码。原回调及options直接交给原生API，重复注册和删除按原身份处理；URL创建/回收、计时器完成/取消分别推进资源代次。停止观测不取消或移除原应用资源。自动once/signal移除或访问器选项无法完整证明时明确记为未知，不将推测当资源已释放。

本轮覆盖登记字段赋值、40个方法入口及解析到的调用点。外部直接修改嵌套对象、提前缓存的原方法引用、反射修改后恢复、未登记资源、全部DOM缓冲和自动移除生命周期仍未完整覆盖。原弹窗焦点通知也可能使旧检查先行失效；新增检查不把所有变化都宣称为旧检查漏检。完整新鲜性、全工作台资源解绑与原子安装继续保持未实现。
