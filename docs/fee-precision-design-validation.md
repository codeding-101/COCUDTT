# 第六十三轮：精度选择与差额审计实现前验收

2026-10-18。交付[精度设计](fee-precision-design.md)、[固定合成案例](cases/fee-precision-design.json)及[独立检查器](../tools/check-fee-precision-design.mjs)，加入Windows/Linux CI。没有新增生产计算、项目/账单/配对/附件字段、精度控件或费用应用。

## 独立设计证据

- **53个固定有效案例**：HALF_UP/HALF_EVEN/DOWN、0.01/0.05/整数/百万分之一的明确步长、精确正中间与两侧18位边界、循环分数、最大十进制输入及进位、零/未知政策/未知金额；逐行与汇总舍入、未知合计不冒充已知小计；价税和费用净额的正负守恒差额；直接/反向商业及独立海关成分诊断换算、有效期两端；先舍入/先换汇和重复舍入的正负差异。
- **75个固定拒绝案例**：Number/指数/空白/非有限/负数/超限文本、非既约分数及坏分母、未明确或越界步长/方式/依据、混币/重复/空/超行数、原价税不平衡/超额抵扣及海关成分、汇率为零/负数/错币种对、日期错误/未来/不覆盖、商业与海关目的混用、不合口径的海关步长/方式/目标币种、历史日期与未知目的。
- **4860组独立整数构造**：从整数步长数和余数构造金额，用另一种余数边界比较对照，验证候选、正负差额回加和幂等；包含2/3/7/10/113分母，不依赖浮点或Decimal舍入接口。
- **124组精确逆汇率对照**：原值乘明确比例再乘精确倒数，整数交叉运算还原；不先把逆汇率截到6位。

固定预期答案单独写入案例，未由检查器输出反生成。检查器不导入生产模块、不修改输入、不返回可应用状态；生产源码扫描保证设计没有被导入运行路径。53/75/4860/124是独立设计核对数，**不加入应用测试总数**。

这些证据不是生产API、严格业务JSON解析器、真实单据对照、UI存取/恢复/竞态验收或最终费用事务证明。分数长度以合成输入约束核对，不声称完成大文件/性能验收。缩减协议不承担最终来源指纹、版本迁移、重复JSON键、客户文件投影或来源资格检查。

## 领域与来源复核

[设计](fee-precision-design.md)盘点现有六位核心、原账单精度待办、精确成分和人民币计税阶段，并列出政府网站转载第272号令第13/14/19条的链接与复核日期。此处只用来限定商业舍入与海关诊断不能混用，不声称完整法规复核。按任意行/箱/日舍入、自动分配尾差、抵扣资格/汇率和新增税基不在本轮结论内。

原始G=N+T和E=G−X成立，不保证各自舍入后的等式仍成立。检查器保留差额，不把尾差塞入税额、最后一行或新费用；X未知不以N代替E，C不从其他成分推定。即使候选能以6位表示，原`CORE_PRECISION_LOSS`和包含/重叠/税务待办也不因此消除。
