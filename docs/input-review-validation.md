# 第四十九轮：输入精度与单位核对验收

2026-10-16。核心输入后新增默认收起的只读核对面板。提示不加入引擎错误/告警，不改计算状态、排名、确认、项目格式或导出金额。

## 范围与精度依据

检查核心数量、货值、采购成本、当前报价/比较目标、商品单位、当前术语活动USER费用的六种计价方式实际参数，以及汇率行。停用费用和当前计费方法未使用的旧参数不解析；不补零。税率、其他术语独立合同报价、保险、账单和付款文件仍在原模块核对，本面板不声称完整检查。

依据当前源码：`src/domain/decimal.ts`采用40位有效数字，常规`q()`处理保留6位小数，卡片通常显示2位；中国进口税款等有独立到分的舍入路径。固定/实际金额与数量、比率等操作数分别提示，不能把乘积处理误写成所有操作数预先舍入。汇率按6位处理，绝对值0.0000004归零、0.0000005不归零；提示不证明当前交易使用了该记录，也不自动取倒数。

超过40位有效数字，或整数位数加6超过40，提示核对数量级、单位和币种。阈值只是保守复核提醒，不是法律上限、实际溢出结论或可支持金额保证；中间乘除仍可能影响末位，未触发提醒也不证明精度。检测只做十进制文本分析，不用二进制浮点重算。科学记数法等只提醒格式，是否接受仍按原校验。

空白或像本项目币种/货币符号的数量单位提示人工核对；件/箱/千克不推断转换，不拒绝合法负数冲减，也不把分数单位自动改整。商业日期不按任意天数判错，海关汇率有效期继续按原规则。

## 交互与数据边界

提示键绑定具体字段和提醒类型，不包含金额或列表索引。点击先提交当前输入，再重新匹配当前提示和唯一原DOM字段；消失或重复目标不跳转。费用/汇率定位进入现有手机高级面板，返回恢复原提示入口；核心字段留在主界面。文件中的显式费用汇率没有独立编辑框时，如实定位费用记录；独立报价模式的项目报价基值如实定位比较基准。

输入待更新时隐藏旧提示正文和数量，重算后显示本次文本。面板每次最多显示30项，明确剩余数量，单个原文截取80字符并注明原长度；原数据未截断，输出转义防止HTML注入。展开、定位和提示状态不写入业务文件。极端文本测试仅验证提示与有界展示，不声称所有极端输入都能由原引擎准确/安全计算。
