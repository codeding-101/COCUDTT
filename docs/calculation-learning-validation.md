# 第四十七轮：计算教学展示与实际记录验收

2026-10-15。工作台第二阶段继续交付，只增加只读解释和导航。费用归属、计税、退税、利润、汇率解析、文件格式及客户公开字段规则保持。

## 用户路径与口径

当前结果摘要下新增“读懂本次计算”入口和默认折叠面板，新手与专业模式均可使用。三个展开区分别为报价/利润与买方支付、逐笔费用的原币→核算→汇总、海关计税组成。

报价、采购成本、承担费用、利润和买方支付直接展示 `AnalysisResult.calculations` 中的原公式、实际操作数与完整计算值。逐笔费用列出原币计价结果、核算金额、实际解析汇率、来源类型、汇率簿编号、解析日期、反向报价标记及汇总去向；固定/实际USER费用另列原始金额文本。海关组成使用独立组件的汇率和计算记录，不借用商业解析重新求值。

原始输入可能比引擎6位精度更多；例如8500.123456789012345678 USD分别显示原始文本、8500.123457 USD计价结果和59500.864199 CNY核算结果（商业汇率7）。两位小数卡片不是解释算式的输入。解析日期不是来源有效期认证，来源文字也不代表已核对。

当前结果继续使用本页录入报价；目标毛利率、目标买方支付和逐术语实际合同报价比较在原完整对比中查看。教学面板不把反推价格当成当前收入，也不修改比较基准或排名。

未启用费用只列名称/编号和“未计算”，不补零或解析汇率。未知采购成本与利润、不适用及未决费用保持原状态。派生税没有独立商业汇率时不补设1；本币计税或通用模式回退沿用原公式说明。费用承担、报价/父项包含、汇总去重与海关加计分别核对；未独立列入税基不代表法律上免税。

## 导航和输入状态

费用可跳转完整责任/去重依据；汇总和海关组成可跳转原公式、进口税额及四张原图表。目标通过当前结果和确切dataset匹配，不将用户编号拼入CSS选择器。导航展开所有祖先折叠区并移动键盘焦点，不编辑输入或撤销确认。

输入待更新时隐藏旧教学记录，点击教学入口或跳转前沿用原输入提交和重算路径；重算失败不显示旧面板。展开状态只在本页界面保存，不进入项目、配对、内部付款或客户文件。新面板未加入内部导出，现有内部报告仍保存原解释记录；客户投影保持原白名单。
