# 诊断格式计量与原5秒复验设计

2026-11-02，第118轮，本地候选。

本轮处理独立诊断编解码器的重复字符串扫描，不调整交易公式、格式或预算。旧关闭测试把三种完整存档往返放在一个原5秒用例内，历史上出现超时。CPU采样集中在格式检查和恢复；重复计量是可确认的额外工作，不能据此认定所有时间波动都有同一原因。

UTF-8和两层JSON转义长度在一次严格扫描中计数；合法代理对仍按4字节，孤立代理字符仍拒绝。原forest中未使用的计量改为已有UTF-8校验，键名仍严格校验。inspect保留文本表全部检查，并复用刚验证的指标；只在本次调用内存储，最多4096项，重复、顺序、引用、未使用文本及全部根预算仍检查。没有全局缓存或解析结果复用，没有减少业务/历史校验。

未改的Node编解码器继续作参考。新旧COMPACT/PRETTY_LF线格式、字节摘要、负零、未知原文和预算必须一致；全部BMP非代理字符、控制字符、共享阈值及代理对边界参与对照。无效Unicode必须在首次加密前拒绝。旧测试和5秒限制保持，不以延时、跳过、减少场景或增加线程获得通过。

连续三轮原测试加完整回归仅证明本轮本机结果，不代表所有环境稳定或原25分钟双平台CI可满足。隔离浏览器的资源接口检查不证明原应用已经解绑；完整切换及正式接入继续关闭。第117轮失败和首次中断开始快照缺口如实保留，不能补造原始源码绑定。

工程门禁先后正确拦截旧原生与恢复格式报告的编解码器指纹变化，两次失败保留。旧测量的限定投影只把编解码器指纹保留为当时版本；投影前先严格核对当前源码白名单与全部历史报告，其他源码指纹不放宽。新测量和本轮机器报告始终使用真实当前指纹，另行核对26组新边界及原接口；旧报告不冒充本轮完整工作台测试。历史检查脚本本身恢复原字节。MJS证据绑定在完整回归后更正，TypeScript保持已通过的版本，原生与全部工程门禁另行复验。
