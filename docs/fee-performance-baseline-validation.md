# 大资料性能基线与容量限制

2026-10-21，第八十五轮。先测量，再决定状态整理方案；本轮没有修改运行工具、财税规则、正式文件格式或大小保护。

## 方法与复现

[Node命令](../tools/benchmark-fee-workbench.mjs)运行原十组控制器、严格解析器、指纹、完整预览、候选准备与备份编码。[真实页面命令](../tools/benchmark-fee-browser.mjs)通过离线单文件原控件进行文件采用、预览及检查备份。两者使用[独立合成夹具](../tools/fee-performance-fixture.ts)，每行113 USD、显式商业换算7 CNY/USD，各自箱号与映射，不是真实业务或税务依据；测试用明确确认不进入运行工具或可下载EXAMPLE练习包。

```sh
npm ci
npm run benchmark:fees -- --counts 1,4,8 --repeat 3 --output benchmark-results/fee-workbench-node.json
```

浏览器命令连接用户自行启动的独立临时Chromium/Edge调试配置。必须设置 `FEE_PERFORMANCE_DEDICATED=1`、`BROWSER_CHECK_PORT`，可设 `BROWSER_CHECK_OUTPUT`、`FEE_PERFORMANCE_COUNTS`、`FEE_PERFORMANCE_REPEAT`，然后运行 `npm run benchmark:fees:browser`。脚本会清空该测试配置的localStorage，禁止指向日常浏览器；不会自行启动或关闭浏览器。默认输出在被git忽略的benchmark-results目录。

[原始机器可读报告](cases/fee-performance-baseline.json)含实际环境、源文件Git blob指纹、每个样本与计时范围，不含业务原文或用户路径。环境为Node v24.19.0、win32/x64、16逻辑CPU、AMD Ryzen 7 7840H w/ Radeon 780M Graphics，页面为Edg/155.0.4283.62、1440×1000模拟视口。最终Node和浏览器测量顺序运行，期间没有其他本项目测试或基准任务。

“首次”是夹具构造、文件采用及结构检查后的第一次计时，**不是冷进程、冷浏览器或冷系统启动**。另列三次重复样本的最小/中位/最大，不报告p95、不设机器速度CI门槛，不从一台桌面推断手机性能。Node模块加载另列，夹具构造耗时不算预览耗时。各阶段有重叠，禁止相加。

## 实测结果

| 合成成分数 | 封套原文 MB | Node完整状态预计 MB | Node完整预览 | 原页面完整预览 |
|---|---:|---:|---|---|
| 1 | 1.2 | 32.5 | 可完成 | 可完成 |
| 4 | 6.9 | 199.6 | 容量保护前停止 | 检查未完成，未形成候选 |
| 8 | 21.5 | 637.7 | 容量保护前停止 | 检查未完成，未形成候选 |

MB为十进制；既有状态保护为134,217,728字节（128 MiB）。Node工具使用[字节计数器](../tools/fee-performance-size.ts)计算完整普通JSON的准确字节数，不生成超大外层字符串；超限时不把未保护对象安装、预览或准备。未执行的阶段与财务候选断言为null及明确NOT_RUN状态，不能读作零耗时或已通过。独立试测的4笔完整捕获亦由原严格JSON保护拒绝；原页面只记录其实际拒绝结果，不凭界面文案推断内部异常类型。

1笔Node重复中位：捕获330.2 ms，严格封套解析85.9 ms，规范化SHA-256 5.7 ms，完整预览2523.9 ms，候选准备2682.9 ms。

1笔真实页面从原生鼠标点击到结果并经过两次动画帧的重复中位为6096.4 ms；包含完整捕获、校验、准备与绘制。备份原动作重复中位为1235.8 ms，包含保存API替身中的原文读取、检查和哈希，**不包含实际磁盘写入**。字段change事件到两帧的结果另列报告：首次修改撤销已准备候选及客户确认，之后重复修改不再有旧候选；恢复名称后由脚本明确重新勾选客户核对。不是键盘逐字输入或独立绘制采样。

Node控制器环境不含DOM及完整页面字段，与真实页面的字节和耗时不能混为同一测量。4/8笔页面拒绝所用时间是拒绝耗时，不是成功预览的性能值；对应候选/备份指标保持null。脚本未对超限状态尝试完整检查备份，因此不声称该备份可成功；六类正式文件仍各有原入口。

## 发现与保持边界

- Node预计状态中retained_json约占80%以上；来源原文又出现在文件证据、控制器、工作区和存储快照，多层字符串转义进一步放大。这里是字节定位，尚无逐函数CPU采样或内存峰值测量，不把全部耗时归因给某一个解析函数。
- 1笔通过原实际引擎和十组准备；候选买方增量为113×7=791 CNY，卖方利润仍未知。只预览与检查备份，不进入整批确认或费用应用；当前项目、封套回执原文及客户原确认在预览阶段保持。
- 4/8笔虽然来源封套可以解析，完整运行状态不能完成检查；这是当前明确限制。本轮不放大128 MiB保护、不截断原文、不缓存过期财务结果，也不把压缩备份当成导入或确认权限。
- 机器可读报告不是可导入业务模板；合成来源确认只为软件测量，不证明税务资格、真实订单、真实历史或全局未重复。
