# 中英文条款摘要验收（第十六轮）

## 功能与含义

客户公开预览增加可展开的中英文摘要，以及检查后“导出中英文条款摘要（HTML）”。原生静态 HTML 在本机生成，可独立打开/复制文本/打印，断网可用；不调用翻译服务，不增加依赖。标题、标签、系统标准提示和已知待办使用固定对应模板。客户自行输入的商品、地点、付款、范围及备注保留公开原文或数据，显眼标注未自动翻译，避免把原文变成未经确认的英文承诺。

摘要只接收 CustomerQuote 公开白名单，从 CustomerDocument 取明确行项，金额保留十进制精度，不读取或附带项目、内部成本/利润、来源、保单、合同凭证或假设。用户主动填写的公开内容仍须检查；没有隐藏数据、执行脚本、外链资源或 JSON 附件。模板版本 1.0 独立记录；客户说明 1.0、项目 0.8、费用规则 1.2 保持，核心计算引擎未改。

风险英文同时匹配术语、引擎中文分支及待确认标记。FCA 区分卖方场所完成装货、其他地点在卖方运输工具上准备卸货、地点未确认；不能直接套通用一句话。CPT/CIP 保留多承运人及另约交货点条件，C 类风险转移与卖方支付运费的终点分开。DAP/DDP 是准备卸货，DPU 为卸货完成。CIF/CIP 的默认险别分别为 (C)/(A)，标准保险基线写明至少合同价 110% 与合同币种，同时说明另约和实际保单须另核，不认证保单。其他术语不凭保险费用推定对方投保义务；DDP 费用承担不推定法定纳税人或抵扣资格。所有权、付款、违约及语言优先顺序须另约，工具不指定优先语言。

已知待办逐条保留中英文；生成日期在报价有效期外时追加两语提示，不修改有效期。未来未映射待办保留中文并标记英文待确认。基础分支/义务不匹配时停止摘要生成，原 HTML、Excel、PDF 路径保留。没有查阅或清除待办就不会将草稿变成确认合同。

点击时先生成公开文档快照，再打开文件选择器；等待期间编辑不能改变这次文件。摘要忙碌防止重复点击，修改项目或公开字段撤销客户检查，新建/打开重置。取消、写入失败及下载回退不改变项目保存、草稿或来源确认；保存 API 失败不另行偷偷下载。
