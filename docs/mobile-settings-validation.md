# 第四十八轮：手机高级设置与返回验收

2026-10-15。700px及以下新增高级设置全屏入口。费用、汇率、税务及原高级资料在同一原表单中编辑，桌面保留原路径。独立账单、配对和付款仍使用原面板，本轮未把所有专业功能改为二级页面。

## 设计与状态边界

原高级设置节点暂时移入原生dialog，退出后放回原位置；没有复制字段、创建第二份交易状态或改变计算路径。面板显示当前保存状态及提示，提供返回、打开和保存入口。原生模态与显式Tab边界限制焦点；字段帮助可以作为上层模态打开，关闭后返回面板内原字段。

返回按钮或Escape先提交尚未提交的金额/来源输入，再恢复调用入口、背景滚动和body样式。同一项目重绘保留面板内部滚动、展开状态及原字段焦点。窗口改宽后退出全屏，把同一输入节点放回桌面位置，保留尚未提交文本。程序异常先关闭帮助和高级面板，恢复body，避免挡住原恢复操作。

费用、汇率与税务错误定位可打开移动面板并聚焦原字段；核心字段仍定位主界面。所有定位使用实际DOM及确定的dataset匹配，不根据错误文字推断业务字段。返回/滚动/模态状态只留在内存，不进入项目JSON、配对或客户文件。

打开/保存沿用原文件路径、快照和读取修订保护：取消、解析失败及写盘失败保持当前资料与面板；成功导入新项目退出旧范围、清除旧返回位置并回到新项目顶部。读取期间编辑使迟到文件不能覆盖当前输入。保存仍会更新文件的updated_at，不把另存操作当成业务确认。

帮助及高级面板都检查原生close事件对应的当前开闭状态，已重新打开的面板不会被旧关闭事件清除；补充两项专门回归。
