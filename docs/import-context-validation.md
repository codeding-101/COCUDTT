# 中国进口业务前提：实现与验收

日期：2026-10-11；本文保留第四轮项目格式0.4与421项测试的历史记录。当前格式0.5，后续见 [买方流程与报告验收](buyer-workflow-validation.md)。承接来源与排名检查，补充人工录入的贸易路线和资格条件。本轮未自动判断国别待遇、原产地或抵扣资格。

## 规则依据和产品选择

| 官方依据 | 实现方式与边界 |
|---|---|
| [关税法](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5234556/content.html)第11–13条：税率适用涉及原产地和待遇条件，并有其他适用规则 | 出口国/地区与原产国/地区分别录入；所选口径及条件单独人工核对；协定税率需填协定名称。程序不因国名或HS编码自动选择税率，也未自动执行各税率比较适用规则 |
| [增值税法](https://shanghai.chinatax.gov.cn/bstax/ztzl/yshj/ldjj/202512/t478641.html)第16、22条：进项抵扣需要合规凭证，部分项目不得抵扣 | 勾选进口VAT抵扣后检查人工身份、用途及独立资料记录。当前产品只接受一般纳税人、可抵扣应税经营的全额抵扣假设；这项限制是模型范围，不能推导为所有其他情况依法均不可抵扣 |

来源访问日期2026-10-11。详细条件仍须查验实际单据和适用政策。记录“用户已核对”不等于海关、税务机关或程序认证。

## 已实现行为

- 项目与引擎保存出口国/地区、进口国/地区、原产国/地区和申报制度；缺失、不属于中国目的地或未确认一般贸易时，金额仍供参考，该方案退出排名。
- 原产地与关税待遇条件有独立来源记录，与税率数值来源分别核对。协定名称缺失时不参与排名。
- 开启VAT抵扣后，身份、用途与核对记录缺失时退出排名；其他或混合用途暂不支持全额抵扣排名。未勾选时按不可抵扣计算，不要求抵扣证据。
- 国家/地区、制度、商品编码、申报日期或模型变化会撤销对应资格确认；关税口径/协定名称变化撤销待遇确认，身份/用途/抵扣开关变化撤销抵扣确认。文件外改动也通过快照检查识别。
- 结果列出贸易路线、制度、关税口径、协定及VAT假设，并展示实际核对记录和原因。
- 0.4兼容读取0.1、0.2、0.3。旧文件缺失条件仍缺失，不猜测、不自动确认；旧版程序拒绝0.4避免忽略新字段。
