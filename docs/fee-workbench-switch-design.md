# 完整工作台切换前状态盘点

2026-10-30，第109轮，本地只读原型。承接[最小继续编辑](fee-package-continuation-design.md)，先核对完整表单、未保存输入和生命周期边界，再设计正式切换。

[源码盘点](../tools/fee-workbench-switch-inventory.mjs)使用已锁定TypeScript7的解析接口，读取十组绑定状态、五组未绑定控制器、三组全局集合及相关监听器、定时器和对象URL的位置。字段名与运行时持有者逐项比较；未知、遗漏或新增字段会阻断检查。此清单覆盖当前明确列出的持有者，不证明所有闭包和DOM缓冲已安全迁移。

[只读检查](../tools/fee-workbench-switch.ts)区分未保存、未提交、进行中和未知状态，独立显示保存证据未知、脱离页面的输入、未读文件、弹层和捕获失败。检查不调用提交、费用准备、保存或切换。客户核对与文件保存不相互替代，自动草稿也不是独立备份。

## 按状态分别处理

| 状态范围 | 已验证的处理方式 | 完整切换前还需完成 |
|---|---|---|
| 交易、报价与项目费用 | 从最新已提交项目重建独立持有者；七字段沿原校验编辑 | 实际独立报价、费用及专业字段的完整表单；不得用公共模拟金额补实际报价 |
| 汇率行与配对汇率保留信息 | 按当前项目汇率簿重建；原档案中的坏行和未完成文本只保全 | 原币文本、无效行、汇率行身份和配对保留键的重新录入及失效规则 |
| 账单、配对、成分、精度与封套 | 最新已提交五类来源加封套按原解析器重建，历史记录和备份完整保留 | 各自完整编辑入口；来源失配、退休编号和历史未知不能被迁移清除 |
| 费用提案、来源核对、成分和精度编辑器 | 未提交编辑仍保留原档案，不安装为已提交资料 | 明确重录、校验、放弃及单独保全；未读文件不能凭文件名恢复内容 |
| 付款与资金计划 | 原档案中的计划原文保全；新最小独立副本保持未录入 | 依当前术语实际报价重新绑定和录入，独立保存与未保存提示 |
| 敏感性参数 | 原档案保留，最小独立副本使用中立控件 | 按原参数校验重录；假设不改变原项目或实际付款事实 |
| 客户公开字段及旧核对 | 原档案保留，新副本公开字段为空且客户核对为否 | 公开白名单重录、重新核对及客户导出隔离；旧确认无审批效力 |
| 显示模式、折叠、证据展开和弹层 | 有独立显示原型；当前真实页面状态仍归原页面 | 明确采用偏好、焦点/滚动处理、弹层关闭及新根关联；不迁移原DOM节点 |
| 快捷费用选择与最近项目候选 | 盘点原控制器字段，不复制旧选择或执行资格 | 原项目身份订阅、跨缓存变化失效和未保存处理；缓存不是备份 |
| 子文件保存证据与完整交接回执 | 子文件证据未知时保持未知；完整交接须独立手动确认保存 | 不以外层包已下载推断所有子文件已保存，不以草稿持久化清除待保存 |
| 根、任务、监听器和对象URL | 现有根保持；新只读检查不接管任务或安装监听器 | 取消并等待物理任务、撤销候选、解绑/重绑和失败保持；当前原beforeunload仅检查封套相关状态，不是全表单关闭保护 |
| 消息、计算与页面缓存、未知扩展 | 消息及缓存不当作业务确认；未知扩展随原始输入保全 | 按新来源重算/重绘、明确列出不支持项；不得执行归档补丁、候选或旧确认 |

源码字段逐一标记为保全待核对、原校验重录、无执行资格或切换前等待/撤销。该标记是迁移设计边界，不是自动赋值或丢弃规则。未绑定控制器中的WeakSet、DOM引用、回调和存储适配器不能因字段名已盘点便序列化复制。

报告身份只对当前检查器、已绑定根修订和当前观测值有效。复制JSON、跨检查器或已绑定根ABA不能重获身份；未绑定状态在两次观察之间变化后又变回，当前方法不能识别，故明确保留未绑定ABA订阅的实现缺口。无输入阻断也不表示可切换，完整表单、全部DOM缓冲、监听器解绑/重绑、关闭保护和最终原子安装仍须后续完成。

[诊断面板](../tools/fee-workbench-switch-panel.ts)仅显示状态和缺口，不显示业务金额或客户原文，没有切换或批准按钮。原工作台通过开发期内存变换挂载观察桥；正式源码和离线工具不接入观察入口。原始资料、旧候选和历史确认继续按原边界处理。
