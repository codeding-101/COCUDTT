# 项目格式、迁移与模板验收（第十七轮）

## 交付与边界

新增两份离线Draft-07 JSON Schema：[当前0.8](../schemas/project-0.8.schema.json)和[兼容旧容器0.1–0.8](../schemas/project-import-0.1-0.8.schema.json)。元数据来自现有结构验证器，不维护第二套独立字段表。允许未完成数值文本与未知扩展，Schema检验不证明可以计算、资料已确认或法规适用；跨不同费用对象的重复ID由应用额外拒绝。Ajv 8.20.0为锁定开发依赖，不进入浏览器运行时。

[四种固定模板](../templates/README.md)可在工具内下载，再用“打开项目”导入：空白中国进口、集装箱费用核对、实际报价比较及合成公式示例。下载只调用固定工厂，不读取当前交易或客户公开输入。前三种金额、税率、汇率及资格保持空白/未确认；起始SEA/CIF/CNY是可修改的录入默认值，不是交易事实。核对清单将THC、demurrage、detention、查验及报关分开，责任待确认，不猜金额、发生原因或收费范围。合成示例标为虚构，不能作为商品归类或官方税率模板。

格式仍0.8，费用规则1.2，客户说明及双语模板各1.0；本轮没有改变费用、税额、退税或利润算法。客户公开字段、预览检查仍不写入项目JSON。文件兼容说明见[格式](project-format.md)和[迁移](project-migration.md)：只接受结构兼容旧文件、在内存中升级容器版本，不静默补业务事实或开启中国税务模式；未来版本/坏结构保留当前项目，保存原文件前建议备份并另存。尚未提供未来字段语义转换器或真实历史文件全覆盖验收。

`npm run build:catalog`确定生成两份Schema、四份模板及目录，固定模板元数据日期不参与业务日期计算。CI在已有测试、审计、类型和单文件构建之后，重建并检查`schemas/`和`templates/`与源码一致。
