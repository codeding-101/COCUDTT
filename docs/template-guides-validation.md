# 第五十三轮：模板预设与真实录入要求

2026-10-16。快速开始增加“查看全部模板、预设与录入要求”入口；每种模板在下载按钮旁提供用途、已预设、仍缺少、下一步填写和适用范围。说明默认折叠，可在重绘和模式切换后保持展开。新入口提交当前编辑再定位模板面板，不安装模板或改变交易。

## 六种模板

保留原四份中国进口JSON的完整字节：空白录入、集装箱费用清单、实际报价比较、合成公式演示。分别说明无费用不等于零成本、集装箱包含/重复范围、逐方案报价缺失，以及虚构税率/日期/汇率必须替换。独立账单和费用清单保持不同用途，未启用消费税或VAT抵扣不表示已核实税务资格。

新增两份确定性、独立项目文件：

- `professional-blank.json`：空白专业模板，通用成本口径；无金额、数量、单位、日期、费用行或汇率簿。进口税率、出口税率及退税率均为空，不填默认零。人民币、海运、CIF和固定报价只是可改起点；打开后可自行切换专业界面，文件不保存界面模式。
- `cif-synthetic-example.json`：基于既有CIF数值用例，净价100,000、运费8,000、直接录入保险费300、报价108,300 USD及采购成本620,000 CNY。日期固定，税率/税目/汇率为虚构，已支持的来源记录标为EXAMPLE；没有人工确认。通用口径不是完整中国出口税务流程，也不根据保险费反推险别或保额。

未修改的完整模板导入后，顶部显示对应名称与待填/示例说明。识别同时比较完整序列化内容，不根据文件名或项目名猜测。修改金额/时间或添加未知扩展的业务文件不会被标为原始模板；文件键顺序变化等导致不匹配时使用普通项目说明，业务内容不受影响。

目录说明升级为1.1，项目格式仍为0.8；目录时间和文件固定生成时间不是业务日期。说明存在独立模块/目录中，不写入项目、客户文件或计算输入；返回的目录为独立副本，不允许调用方通过目录对象修改页面说明。
