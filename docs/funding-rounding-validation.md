# 金额舍入假设与层级差异验收

第二十五轮，2026-10-13。开发候选，不合并发布。范围为单主体、单币种、明确年基数下的非负单利金额舍入假设；不代表银行账单、应付利息确认或真实扣款。

## 显式输入与兼容

付款1.4仅通过1.3计划的独立启用创建。原付款、本金、利率和扩展保留，资金测算状态及新舍入状态归待确认。新建计划仍默认1.1；项目0.8、恢复1.0及旧四份1.2合成资源保持。旧1.3同名funding.rounding扩展仍未知、原文往返，升级时拒绝覆盖；旧版计算不激活舍入字段。未来1.5及坏结构拒绝替换已有计划。

funding.rounding包含以下字段；结构允许保存未完成草稿，业务就绪另查。

| 字段 | 范围与含义 |
|---|---|
| status | UNCONFIRMED / NOT_APPLIED / APPLIED；未知不是已舍入，明确不应用不证明银行不舍入 |
| scope | UNCONFIRMED / TOTAL / INTERVALS；整个期间合计后舍入，或每个计算区间舍入再相加 |
| mode | UNCONFIRMED / HALF_UP / HALF_EVEN / DOWN |
| unit | 正十进制金额步长文本，例如0.01、1、0.001或0.05；不从币种推定，不默认两位小数 |
| reference | 金额步长、方式、层级和舍入时点的用户依据文本，应用时必填 |
| intervals_confirmed | 布尔值；逐区间应用须明确确认计算区间就是拟采用的舍入边界 |

步长不接受空白、0、负数、指数、千分位、分数表达、NaN或超过80有效位/40小数位的值；允许很小或很大的正步长，但真实性依合同另核。不应用可以保留未完成业务输入，结构仍须合法。整个资金假设明确不测算返回未测算，不当零。

HALF_UP取最近的整数个步长，恰半向上（本模型非负）；HALF_EVEN恰半取偶数**个步长**；DOWN向零截断。数学名称核对[decimal.js官方舍入定义](https://mikemcl.github.io/decimal.js/#modes)，不是引用银行统一结息政策。例如金额0.125、步长0.05为2.5个步长：取偶得到0.10，恰半向上得到0.15。

## 舍入时点及边界

TOTAL是对整个测算期间精确单利合计舍入一次。INTERVALS是对本金/利率生效日合并形成的每个非零天数区间舍入一次再相加，不再次舍入合计。恒定本金/利率只有一个区间；同日事件不造零天数区间，截止日事件不新增计息或舍入区间。零天数为0个区间，原始/舍入合计均明确为零，但其他假设仍需就绪。

计算区间**不能自动等于银行结息日**。逐区间应用必需intervals_confirmed；日期、起止日、模型切换或增删事件会清除此确认，须重新核对。切换舍入层级将舍入应用状态设回待确认。合计模型也展示“若逐计算区间舍入”的比较值，这只是层级差异，不证明该边界实际适用。新增无金额/利率差异的事件也可能拆分区间并改变逐段舍入结果，不自动净额合并或推定结息。

本轮不支持自定义结息日、逐日舍入、每月账单、年度应计转结、利息资本化、最低收费、复利或实际银行扣款确认。其他合同约定不能套用本模型。

## 精确算法与独立手算

保留原始FundingResult.cost及原计算算法，新增rounding审计对象。每个区间从十进制本金/实际年利率及整数天数重建精确分数，使用BigInt约分、求和和余数比较；不把256位循环小数或12位显示值再输入舍入器，不使用JS浮点金额。金额步长分数化后求整数个步长，半数与奇偶判定精确。

舍入金额、两层级差额均为精确的整数个步长；显示小数位沿规范化步长，例如0.01得到0.02、0.00，不默认货币精度。原始值及舍入调整的十进制最多256有效位，循环小数标明展示限制；原始及调整的精确分数另列，可完整核对。符号差额可为负，不造负零。算法没有改写合同价款、银行费、税费、利润或落地成本。

合成手算：本金6 USD、年利率36%、ACT/360，09-01至09-04，09-02和09-03显式生效记录仍为36%，产生三个1天区间。每段`6 ×36 ÷100 ÷360 = 0.006`，三段合计`0.018 = 9/500`。

| 方式，步长0.01 | 合计后 | 每段舍入再相加 | 逐区间−合计 |
|---|---:|---:|---:|
| HALF_UP | 0.02 | 0.01×3=0.03 | +0.01 |
| HALF_EVEN | 0.02 | 0.01×3=0.03 | +0.01 |
| DOWN | 0.01 | 0.00×3=0.00 | −0.01 |

合计HALF_UP调整为`0.02−0.018=0.002=1/500`；选逐区间为`0.03−0.018=0.012`。该例证明舍入层级差异，不证明银行会按利率记录分次扣款。前轮利率合成65与固定率案例50保持原始结果。

## 内部审计与持久化

界面区分“原始未舍入”和“舍入假设金额”，列明来源、方式/步长/层级、两种层级对比、各区间金额/调整与精确分数。长循环小数默认12有效位、近似标记并可展开。内部HTML/XLSX复用同一结果，原值和舍入值分列，原始计划含待确认字段单独保留；XLSX是生成时快照，编辑不会重算。超Excel数值精度用文本，依据文本不执行公式。

新字段输入沿用独立付款状态，不写项目0.8或自动草稿、客户确认。付款JSON及内部XLSX均在选择器前固定；编辑取消慢文件读取，不混入本次保存。手动异常备份保留1.4原始字段，界面重试不丢内存输入；恢复检查识别1.4结构而不自动导入。客户公开白名单不读取计划及舍入依据。
