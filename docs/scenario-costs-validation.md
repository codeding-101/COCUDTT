# 按术语启用费用与替代运价验收

2026-10-11；项目格式0.6。承接中国进口买方测算，此阶段让不同组织方式使用实际录入的不同运价。发布候选仍是0.5，用户已选择暂缓合并和发布；本功能另行验证。

## 录入方法

1. 在费用卡片展开“适用贸易术语”，选择所有术语、不启用、常用范围或逐项勾选。未设置时沿用所有术语；空选明确表示不启用。常用范围仅帮助录入，实际组织方式和合同仍须人工核对。
2. 同一运段的替代报价分别录成两项，填入相同“替代报价组”，设置不重叠的适用术语。例如，卖方运价600 CNY适用于CFR/CIF/CPT/CIP/DAP/DPU/DDP，买方运价1,000 CNY适用于EXW/FCA/FAS/FOB。这是合成对照的假设，不自动判定合同事实。
3. 同组最多启用一项，重叠时明确阻断该方案；程序不会把两份替代报价相加或悄悄取较低值。不同运输分段可以同时录入，不要把它们设为同组。
4. 单方案、术语比较和报告先按适用术语筛选，再计算金额、商业/海关汇率、费用依赖、责任和税额。未启用项列在结果及报告中，不解析金额、不要求缺失汇率、不计入税基与汇总。
5. 已启用项若引用未启用基数或声明包含在未启用父项内，会明确报错。缺失的报价只使启用它的术语不可行；其他可计算列保留。当前术语出错时不沿用旧金额，可切换有效术语后继续保存报告。

## 手工对照：同一货物、两种运价

所有金额、税率和资格均为合成测试数据；不是实际商品税率或真实报关记录。货物净价10,000 CNY，保险100 CNY，关税5%，VAT13%，无消费税。固定报价10,700 CNY，卖方采购成本未知。

| 项目 | CIF采用卖方运价600 | FOB采用买方运价1,000 |
|---|---|---|
| 计税价格 | 10,000 + 600 + 100 = 10,700.00 | 10,000 + 1,000 + 100 = 11,100.00 |
| 关税 | 535.00 | 555.00 |
| 进口VAT | (10,700 + 535) × 13% = 1,460.55 | (11,100 + 555) × 13% = 1,515.15 |
| 买方总支付 | 10,700 + 535 + 1,460.55 = 12,695.55 | 10,700 + 1,000 + 100 + 555 + 1,515.15 = 13,870.15 |
| 卖方利润 | 无法评估 | 无法评估 |

此表是“报价金额相同”的比较假设，不能把它当成两份真实FOB/CIF合同报价。各术语启用不同费用时税基也会变化，界面不再宣称税额恒定。

另验证固定买方总支付13,000 CNY反推：CIF报价11,004.45，FOB报价9,829.85；各方案买方支付保持13,000。已知采购成本8,000、目标利润率20%时：CIF报价10,875，FOB报价10,000。百分比计费和迭代继续使用现有机制。

## 后续边界

当前每种术语仍只有一个共享合同报价/比较基准，不是任意多份独立合同方案。接下来可以增加按术语分别录入实际合同报价、报价有效期和运价资料编号，再扩展汇率或运费敏感性。当前不会凭运输承担方自动认定组织方，不自动调整净价、原产地或贸易资格，也不证明保单满足保险范围要求。
