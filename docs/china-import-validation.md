# 中国一般贸易进口模式：规则与验收

核对日期：2026-10-11。文件格式：0.4。目标：先把一票单商品的一般贸易进口测算做成可复核的工作流。

## 使用方式

1. 打开新版网页，点击顶栏“中国进口示例”。示例的税率、汇率和卖方成本全部虚构，用于核对公式。
2. 填写货物净价，不含另列的运输、保险费用；核算币种使用 CNY。填入一般贸易完成申报日期。
3. 在“汇率”面板维护 CUSTOMS 类型的计征汇率及有效期起止。在“进口税务口径”和 HS 表维护实际适用税率。界面不自动抓取税率，也不自动确认协定待遇。
   展开各处“来源核对”，填写来源链接或文件编号、适用期及核对日期，人工核实后选择“用户已核对”。兜底记录共同覆盖关税、VAT及消费税适用性；HS覆盖的字段使用对应条目的记录。商业汇率也需核对。修改数据或来源记录后须重新确认。
4. 逐条核对费用计税标记。默认加计主运输与保险；尚未包含在货值中的应税附加费用可选“另加计税”，不应另行加计的费用可选“不另加计税”。已含于父项的费用仍遵守去重规则。
5. 仅在确认进口 VAT 抵扣资格时勾选“买方进口增值税可抵扣”。示例默认不勾选。
6. 核对结果区的计税价格组成、逐项税额、承担方和告警，再保存项目文件。报价汇率与计征汇率保持独立。
7. 查看“结果核对”的实际来源和待核对事项。中国进口模式下，示例来源、缺失或失效核对记录会令方案退出排名；未确定或未拆分的非零费用、不完整税基及严重错误也会令受影响方案退出排名。满足当前检查条件仍不代表贸易资格或业务数据获得认证。
8. 填写出口国/地区、进口国/地区、原产国/地区和申报制度，独立核对关税待遇；适用协定时填名称。勾选VAT抵扣后，补充身份、用途与资料核对。当前仅支持全额抵扣假设，部分抵扣和混合用途未建模。条件变化后须重新核对，详见 [业务前提验收](import-context-validation.md)。

## 已核对并落实的规则

| 依据 | 本轮实现 | 核验方式 |
|---|---|---|
| [海关总署第272号令](https://www.mct.gov.cn/preview/whhlyqyzcxxfw/ss/202411/t20241106_956082.html)第13、14、19条 | CNY 计税；价格及税款舍入至分；申报日期单独填写，只使用有效期覆盖该日期的海关汇率，缺失时阻断 | 汇率日期与报价、出口日期分离；过期或缺少有效期的汇率簿测试 |
| 同令第17条 | 从价、从量和复合关税；从价消费税；VAT 基数包含关税与消费税，逐项使用已经舍入的应纳税额 | 手工对照与单位匹配测试 |
| [关税法](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5234556/content.html)第24–26条 | 货值加运输、保险和显式加计费用；支持显式排除，结果列出组成 | 附加费用、排除与父项包含去重测试；法定估价要素仍由用户核实 |
| [一票货物免征关税额度公告](https://gss.mof.gov.cn/gzdt/zhengcefabu/202411/t20241129_3948542.htm)及[财关税〔2004〕7号](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5202868/content.html)第三项 | 在单商品一票假设内，各税种按本票税额低于50元独立判断；按舍入至分后的数额比较，50.00元不按低于50元免征 | 49.99、49.995舍入为50.00、50.00边界；消费税免征后VAT基数测试 |
| [2026年起施行的增值税法](https://shanghai.chinatax.gov.cn/bstax/ztzl/yshj/ldjj/202512/t478641.html)第14条 | 保持进口VAT组成计税价格递进计算，未将国内小规模纳税人的销售额起征点套用于进口税 | 递进税基和逐税种小额免征用例 |

工程上新增了有限数值与非负值检查，消费税率必须小于1；非法汇率、重复HS税率和缺失所选关税口径阻断计算。HS上级匹配仅作为估算并提示核对，不等于真实税则归类成立。

中国进口模式不调用中国出口退税计算，也不计算境外卖方所在国税务。卖方利润仅使用录入的成本假设，结果明确标注这一范围。

## 手工对照案例

以下各数字均为演示输入，不对应真实商品税率。

### 案例A：美元CIF交易，无消费税

| 输入 | 数值 |
|---|---:|
| 货物净价 | USD 100,000.00 |
| 国际运费 | USD 8,000.00 |
| 保险费 | USD 300.00 |
| 商业合同汇率 | 7.00 |
| 海关计征汇率 | 7.08 |
| 关税率 / VAT税率 | 5% / 13% |
| 完成申报日期 | 2026-09-10 |

计税价格为 `(100000 + 8000 + 300) × 7.08 = 766764.00`。
关税为 `766764.00 × 5% = 38338.20`。
VAT为 `(766764.00 + 38338.20) × 13% = 104663.286`，舍入至分得 `104663.29`。
税款总计 `143001.49`。

按CIF报价 USD108,300、商业汇率7.00，报价人民币金额为 `758100.00`。
买方承担税款且无其他费用时，总支付 `901101.49`。在示例未确认VAT可抵扣的条件下，两种买方成本口径相同。

### 案例B：从价消费税及逐项舍入

计税价格CNY1234.56、关税率5%、消费税率10%、VAT税率13%。

| 税种 | 算式 | 应纳税额CNY |
|---|---|---:|
| 关税 | 1234.56 × 5% | 61.73 |
| 消费税 | (1234.56 + 61.73) ÷ 0.9 × 10% | 144.03 |
| VAT | (1234.56 + 61.73 + 144.03) × 13% | 187.24 |
| 合计 | 上述应纳税额之和 | 393.00 |

这些用例已写入 `tests/china-import.test.ts`，同时测试从量税单位未知或不匹配时阻断，以及附加费用依赖计税价格时的循环检测。

## 兼容与验证

- 缺少 calculationMode 或显式LEGACY的旧项目仍使用原有口径，不自动变成中国进口交易。
- 新版读取0.1、0.2、0.3文件后升级容器版本为0.4，保存时使用0.4。旧版程序会拒绝0.4文件，避免忽略新字段后误判。此升级不改变旧项目的税务模式，也不自动确认来源或业务资格。
- 当前25个测试文件、421项测试通过；类型检查与单文件构建通过，产物另有脚本语法检查。静态审查结果与来源机制验收见 [来源与排名验收](source-readiness-validation.md)，第四轮验证见 [业务前提验收](import-context-validation.md)。
- 真实Edge通过file://运行：已验证中国示例计算结果、来源核对后的排名、汇率修改导致核对失效、保存/打开数据往返、申报日期导致的过期汇率阻断与恢复，以及坏文件打开后保留草稿与结果。1440px桌面、390px及320px手机视口无页面横向溢出，展开来源与结果面板后也不溢出，无未处理运行异常。手机尺寸为模拟，保存API为替身，尚非手机硬件或真实落盘验收。

## 尚未覆盖的业务

本轮是中国进口模型的基础校正，不能代表完整报关计税系统。暂不支持从量或复合消费税、反倾销等额外税种、关税配额、跨境电商零售进口、保税/暂时进口/加工贸易等特殊制度，以及多商品同一票的小额免征汇总。

显式费用调整提供录入能力，不自动判断特许权使用费等调整要素是否依法应加计，也不替代特殊关系和特殊估价核定。含运保费的整张发票需先拆分净价；同一费用在货值与独立费用中重复录入仍可能重复计税，需人工核对组成。

税率、原产地资格与来源生效期仍由用户维护和核实；来源、有效期及业务条件记录已接入文件、界面与排名检查。下一步应引入真实匿名报关对照案例，并完成买方日常测算流程。网页尚未部署到线上站点。
