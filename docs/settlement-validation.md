# 付款时间表与银行费用验收（第十八轮）

## 功能与基础概念

本轮增加当前术语的内部付款计划，绑定独立录入的实际原币报价；模拟、反推或缺失报价不能作为合同价款来源。TT、L/C、OA只作用户记录的付款主方式，不预填比例、付款日、预付事实或账期，不认证该方式下合同、信用证或单证条件有效。每笔价款填写原币金额或合同价百分比、明确日期及触发条件/合同依据；日期只是约定计划，不表示条件已满足或钱已到账。

分期合计必须与报价精确相等，不自动补尾款或用容差抹掉差额。采用隔离的256有效位十进制实例，输入限制80有效位、40小数位及160字符，避免影响旧引擎40位/六位量化配置。不假定所有币种统一两位小数；例如0.01按30%/70%分配为0.003/0.007，属于精确计划，实际银行最小单位和舍入须另核，必要时改用明确金额分期。不同币种分别汇总，不推定结算汇率。

银行费用默认待核对，空清单不是零费用；用户须明确无费用，或逐笔列出。已有费用通过ID关联当前实际参与分析的用户自定义项，人工确认其属于银行费用，不按名称自动识别。使用原币计费结果，不再添加项目费用。重复关联、待确认责任、非当前方案、已去重/未计入该方、原费用或本术语合同覆盖的付款/承担约定冲突时阻断。新增费用须记录金额、币种、依据，并明确确认未在项目录入；程序不能识别不同ID或名称是否来自同一账单，这项检查由用户负责，不宣称自动防止所有业务重复。

费用经济承担方和实际付款方分别录入；代付/垫付、双方清偿或分摊尚未建模，首版明确退出，不能由承担方猜付款方。计划展示合同价款和银行费流向、各币种买方付款、卖方收款/银行付款及收付净额。收付净额不是经营利润；这里不包含货物采购、其余运保费和税款付款，也不是完整落地成本或实际账户余额。融资利息、保证金冻结、银行净额扣费后到账、抵扣清偿、贴现和收款保证均在首版范围之外。

概念核对日期2026-10-12，交付更新2026-10-13。依据起点：[ICC Incoterms 2020引言](https://library.iccwbo.org/content/tfb/BOOKS/BK_0049/BK_0049_03_Introduction.htm?AGENT=ICC_ACA)明确付款时间/方式/币种及所有权另约；[ITA Trade Finance Guide](https://www.trade.gov/report/trade-finance-guide)区分预付、条件信用证和赊销。这里校准简要软件说明，不作为中国银行操作或信用证条款认证，不替代实际合同和适用规则。

## 文件、状态与隐私

内部付款计划是独立标准JSON：`kind=INTERNAL_SETTLEMENT_PLAN`、`version=1.0`，没有修改项目格式0.8或客户公开白名单。计划包含绑定交易与内部银行依据/备注，按敏感内部资料管理，不直接发客户。客户HTML/Excel/PDF/双语路径不自动读取这份计划。

本页输入不写入项目JSON或自动草稿；刷新、新建或打开项目会重置，必须单独保存付款计划。未完成字段可原样保存再打开，未知扩展保留；结构检验不证明可计算。坏格式或未来版本不会替换已有计划或当前项目；导入合法旧绑定时保留原字段并提示，核对后可显式重新绑定。报价金额、币种、术语、地点、商品范围或项目名变化后退出旧结果，不补造期款。原币格式变动也要求重新核对。

保存前同步生成快照，等待期间编辑不改变该文件，忙碌防重复写入。取消、磁盘错误与下载回退保留输入、草稿、项目保存状态及客户检查；失败不额外下载。慢文件读取遇到新项目、另一次导入或后续付款编辑时不覆盖新状态。内部HTML报告保留生成时付款计算/错误及原输入；内部Excel首版不包含付款计划。费用、税款、退税、利润和推荐算法不因这份独立计划更改。
