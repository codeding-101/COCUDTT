## 原页面与独立模块逐字比较

[浏览器检查](../tools/check-fee-source-adapter-browser.mjs)运行真实app.ts。专用本地Vite验证服务器仅在内存中追加[测试桥接](../tools/fee-source-adapter-bridge.mjs)，同时调用原捕获与独立适配器，比较完整`JSON.stringify`结果、九个根字段和retained_json字符串。生产源码没有桥接导出，正常构建不含该桥接。

27个场景全部一致：默认；未初始化；只有pending；input/textarea/select/checkbox、未连接input及非表单DIV；匹配/修改/未完成/坏FX行；当前/迟到项目读取token；恢复；文件忙碌；下载与明确保存证据；不存在/空/损坏存储、单键/全部不可读；真实等待中的封套读取及三类阻断共同出现；通过原文件输入和明确采用动作载入完整合成资料后再次比较。

每次比较验证所有者修订、项目及封套/回执原文、客户确认均保持。只读比较中每端十次getItem、共20次读取，setItem/removeItem均拦截并要求0调用。合成场景准备和原界面资料采用发生在比较之前，报告没有把这些动作说成没有来源安装；没有使用费用应用入口。

机器可读证据见[27场景报告](cases/fee-source-adapter.json)，含真实app、新模块、桥接/驱动、FX与所有者等源码指纹及浏览器版本。完整合成场景旧捕获32779884字节，新结构帧14446620字节，重建旧捕获逐字相同。两种契约的字节大小不能证明生产容量、速度或内存改善。

运行时需显式设置`FEE_SOURCE_ADAPTER_DEDICATED=1`、专用`BROWSER_CHECK_PORT`和可选`BROWSER_CHECK_OUTPUT`，再执行`npm run check:fee-source-adapter:browser`。检查只清理专用测试资料；浏览器需由操作者单独启动和按身份关闭。真实用户浏览器不能用于该脚本。
