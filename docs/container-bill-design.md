# 集装箱账单假设：独立模型与接入门槛

第三十三轮，2026-10-14。先写规则，再实现独立计算；此阶段不接入运行工具、项目JSON或客户报价。输入/审计API版本0.1不是项目版本。结果始终为ASSUMPTION_ONLY，来源文字不等于专业确认。

## 依据与边界

本日核对[Maersk D&D条款](https://terms.maersk.com/dnd)：demurrage为箱在码头/港区/堆场内的超免费期占用，detention为区外占用，联合D&D覆盖内外合并期间；是否分开收费以及storage是否另收，须看当地及合同口径。[加拿大进口页面](https://www.maersk.com/local-information/north-america/canada/import)明确展示免费期工作日、收费日历日并存及0800事件截点；这些是地区示例，不能当中国或所有承运人的默认。[Hapag-Lloyd费率入口](https://www.hapag-lloyd.com/en/online-business/quotation/detention-demurrage.html)要求选择国家且说明可能变更。本模块不内置上述运价。

第一版只接受**免费期和收费期都为日历日**、明确本地业务日期的假设。工作日/节假日、小时截点、部分日进位、暂停或豁免、冷藏附加、SOC例外、按整段最高阶梯追溯计价均需另建规则，输入这些模式直接拒绝，不能静默按日历日替代。原始事件先人工转换为适用合同的日期和是否计入两端，不自动从卸船/提箱/还箱事件推导日期。

## 输入

最多50条账单行；每行包含唯一line_id、人工scope_id、IMPORT/EXPORT、箱型equipment_type、1–50个唯一container_ids（长度是箱数）、币种、非空来源reference。箱ID是用户稳定标识，不宣称验证ISO箱号；同一行箱型/事件/免费期/费率必须相同，不同则拆行。字符串ID最长200、来源4000；币种为三个大写字母，仅标签，不假定币种小数位或合法货币数据库。

| 费用 | 计费模式 |
|---|---|
| THC_ORIGIN、THC_DESTINATION、INSPECTION | PER_CONTAINER：每箱明确固定rate，不附加日期/免费期 |
| DEMURRAGE、DETENTION、COMBINED_DD | DAILY：明确period和daily规则 |

固定项仅支持每箱，不代表THC或查验在实务中总按箱收取；按票、按次、重量、最低收费、税额和附加费另行处理。不得用单箱虚拟项掩饰按票收费。

DAILY的period须明确start_date/end_date、两端included布尔值和start_event/end_event原始事件文字。日期格式YYYY-MM-DD，范围1900–9999，结束不能早于开始、端点跨度最多3660天。选中日期区间=两端按included裁剪后的连续本地日期；同日双方都计入为一天，其余为零天，不能产生负天数。UTC仅用于无时区日期整数运算，不把账单改成UTC事件。

daily须明确free_day_basis=CALENDAR_DAYS、charge_day_basis=CALENDAR_DAYS、free_days整数0–3660、tier_mode=MARGINAL和tier_basis：AFTER_FREE_TIME为免费期结束后收费日1起，FROM_PERIOD_START为所选期间第1日（含免费日）起。免费日是选中期间最前free_days天，每行独立，不共享免费池。不能用该字段表示已耗免费期后的截取账段；这类输入须提供完整适用期或待后续专门建模。

tiers为1–20个连续边际阶梯，每阶through_day为正整数严格递增，最后且仅最后为null（无上限）；rate是非负十进制字符串，最多24位整数/18位小数，不收数字、指数、负值、NaN或空白。第1阶从日1起，后阶从上一through_day+1起。收费日逐日选择该日所属阶梯，不能用最后日费率回溯整个期间；费率允许下降及零，不擅自推定递增。

## 输出与防重复

逐行保存输入快照、箱数、选中天数、实际消耗免费天数、未用免费天数、收费天数、逐日日期/序号/免费或收费/命中阶梯/原日率/每箱及整行金额，并按阶汇总天数与金额。固定项每箱率×箱数。内部以18位定点BigInt精确乘加，输出十进制字符串；不隐式采用原引擎六位量化，不假定两位小数、不自动账单舍入、汇兑、税费或责任归属。

相同scope_id及进出口方向、共同箱ID、选中期间交集：同类DAILY、联合D&D对demurrage/detention以及分开D&D共享日期均列候选；共享提箱日也保留候选，合同可能区分时间段，不能自动判定重收。同类固定每箱项列范围候选。不同scope/类别不证明绝无重复，跨类别内含THC仍需合同核对。没有跨行总额，候选不扣减原金额、不把联合和分开项自动相加，不提供“检查通过/可推荐”标志。

函数先校验完整输入，任一坏结构拒绝整份、不输出部分金额；异常仅报告受控字段路径，不回显箱号、来源、文件路径等原值。空lines可得到空审计，但不证明零费用/检查完整。冻结输入可运行、返回快照深复制；不写入CostItem、包含关系、运输风险、完税价格、退款/退税、利润、排名或项目格式。
