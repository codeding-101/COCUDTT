## 不改变的边界

本功能是内部JSON交接和独立只读核对，没有把新项目安装到正式工作台，也没有完整表单重开。浏览器发起下载、浏览器完成事件、操作系统保存对话框与控制注入的失败分别计量，不相互替代。SHA-256不是真实性或专业审核认证。

原财税规则、依赖、正式项目和封套格式、离线运行工具及4／8笔容量限制保持；46套完整财务浏览器与1／4／8容量仅沿用历史，本轮未重跑，不宣称性能或峰值内存改善。真实手机、真实业务单据和人工专业复核仍按用户安排暂缓。完整设计见[设计](fee-recovery-package-design.md)，后续目标见[阶段计划](development-stages.md)。
