# 第五十一轮：内部计算假设摘要验收

2026-10-16。HTML报告前部与Excel“交易口径”首表集中展示生成时的计算假设。原6张基础表、附件顺序、公式、来源和输入快照保留；不新增工作表，兼容现有16表上限。

## 口径与内容

共享投影模块`src/data/calculation-assumptions.ts`输出脱离引用的内部字符串，HTML按表格渲染，Excel写入文本单元格。只读取输入与提供的引擎记录，不选择汇率、重算财务金额、确认来源、清除待办或提升排名资格。

HTML摘要使用当前录入报价的单方案结果；Excel使用方案对比中当前术语的结果。固定目标毛利率/买方支付可能反推报价，两者不混用。实际报价模式使用该术语原币报价，缺失不回退公共报价；当前术语无可用结果时保留原因，不使用其他术语结果或占位零。采购成本未知保留未知。

五组内容：

- 范围与报价：术语/地点/运输、版本、录入报价、比较基准、分别记录的日期、货值/数量/采购和净价口径；实际报价/采购公式直接复制原代入记录。
- 汇率与来源：费用及计税实际解析、方向/反向解析/类型/簿编号/日期/来源，与全部录入簿分别标注。录入记录不代表采用；报价/采购解析以原公式为准，不从公式字符串反推结构化汇率。缺独立记录不补汇率1，通用海关回退保留原说明。
- 费用与计税：原承担、报价包含、双方汇总标记及排除原因；停用费用不解析原金额或汇率。税基只列实际组成和结果，不把全部费用相加，也不由承担/付款推断海关处理。
- 税务与附件：输入模式、VAT抵扣假设与本次实际抵扣额分别说明；原税率/税类/命中编码、退税范围、条件记录和精度说明保留。付款、敏感性分析、账单和配对是否附带只说明独立范围，不证明成功计算、真实收付或费用已应用。
- 待办与比较限制：当前来源/业务问题、告警、物流和运输关联提醒；对比的不适用/失败/未完成原因按相同原文分组并保留涉及术语。未列问题不等于真实业务核验通过。

## 安全与快照

摘要仅用于内部文件。客户工作簿公开投影和序列化入口保持，新增内部来源不会进入客户HTML/Excel/PDF或中英文条款输出。HTML所有字段转义，无表单、脚本、交互动作或外部依赖；Excel摘要为文本，不生成可执行公式/链接。长来源保留并换行；未知不补零、原始汇率文本与实际解析值分别保留。

导出在文件选择前形成快照；等待选择期间编辑交易，不会把新输入混入旧摘要。取消/写盘失败沿用原行为，原业务文件和确认状态保持。付款附件测试现按明确附件标记比对首表，其他基础表仍保持完整内容比较。
