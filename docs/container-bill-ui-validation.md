# 集装箱账单录入与交接界面验收

第三十五轮，2026-10-14。[接入设计](container-bill-ui-design.md)先明确文件、确认、客户隔离和写入边界；本轮更新验收源码/离线工具与main README，公开网站gh-pages保持。

## 完成范围

独立账单面板录入箱组、方向/范围/原币、日历日起止事件/两端计入、免费天数/阶梯口径及边际日率；空值不预填业务事实，0/false/null分别录入。来源用明确按钮确认，状态选择不自动确认；EXAMPLE须先由用户明确改为待核对。原不支持选项保留且可见，切换模式保留旧字段，明确清理才移除不适用内容。

独立1.0 JSON打开/另存和静态Schema/两模板下载；独立本地草稿键，不嵌入项目。打开/新建项目保留账单，不自动绑定；绑定及引用变化待重核。坏草稿启动不覆盖原文，存储失败提示另存。账单修改不改项目脏状态、客户确认、成本、风险、税费或推荐。

页面最多每行预览30日、候选前50对，明确总记录数；完整逐日/逐阶及全部候选随内部Excel，原币金额使用文本保留18位小数，不经原引擎量化或Excel浮点。最多183000逐日拆四张各不超过50000行的表，与既有九表共同保持16表上限；全账单JSON按序分片存档。内部HTML含逐日预览和完整原始账单快照，不能当客户报价。客户HTML/Excel/PDF仍只读取公开白名单。

保存/内部导出/资源先生成固定内容再打开选择器，等待时编辑不改变本次文件；另存完成提醒后续修改再保存。读取由世代计数取消迟到内容，编辑/新读取/项目变化/界面异常后旧回调不覆盖输入。取消、版本/结构/大小及读写错误保留输入，底层私有路径不回显。

原始异常备份1.0增加可选container_bill及container_bill_draft_text，未经重新计算直接存档；重试保留输入。只读检查识别这两部分，当前完整备份八部分，旧文件六部分行为保持，不自动恢复或确认。恢复检查整体仍5MiB，超限原文可人工复原；自动草稿、浏览器崩溃或脚本无法加载不提供无条件保障。

## 下一阶段与限制

已有费用仍只读，未新增/覆盖任何费用，未解除联合/分开及包含候选。下一阶段先设计稳定映射、文件兼容、写入金额精度和具体提案，再验收显式引用已有/新建费用及防重复点击/重算/复制、过期提案拒绝和成对文件失配。不将此界面接入当费用写入完成。

真实手机、人工专业及真实承运人/交易文件对照按用户安排暂缓。来源快照不是签名/认证，程序通过不证明实务或法规适用。
