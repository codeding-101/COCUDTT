# 第七十八轮：运行工作台状态归属迁移

2026-10-19。承接[完整快照提交层](fee-workbench-validation.md)。本轮把实际运行中的状态归到同一内存持有者，保留旧交互；尚未接费用快照投影、整批预览/确认或实际费用应用。

## 实际接入范围

[运行持有者](../src/ui/workbench-state.ts)在[app](../src/ui/app.ts)中统一创建。项目/结果/原始FX编辑行/项目文件状态属于app；原FX保留租约、待处理输入、客户资料与确认、结算/敏感性和读取代次等32个字段属于workflow。五个既有资料控制器、三个资料工作区也实际接入，共10组参与者。

既有公开字段和控制器私有字段通过访问器读取同一根对象；旧方法仍处理原业务规则。环境回调和控制器实例身份保持，不作为可替换资料。启动与异常后首次初始化使用同一入口，重试已初始化页面不重复注册。内部恢复备份增加归属元数据，仅包含参与者名称、代次和字段数量，不导出根对象本身。

32个工作流变量按语法树符号定位迁移，保留对象简写的原键名。项目/客户文件格式、原始金额、业务ID和计算规则没有因此改变；没有新增外部文件格式或自动迁移。迁移工具只放在本机隔离验收目录，项目依赖和锁文件保持。

## 检查点与替换边界

检查点绑定本实例、根对象与单调代次；JSON或其他持有者的同数字对象不能授权。字段改变后改回、交互开始、跨标签存储事件及较晚注册均使旧检查点失效。

可信内部调用可先准备多个参与者的字段替换，再一次替换完整根指针；原控制器视图即时读取新根，不逐个调用旧setter，也不执行存储、显示或文件回调。未知/重复目标、未知字段、访问器补丁或验证期间重入使整批拒绝或失效，前面的合法字段不先行写入。重复执行原检查点零替换。

**这是运行状态归属原语，不是财务资格校验，也不是深冻结JSON快照。** 为兼容既有表单、Decimal、Map/Set和DOM引用，嵌套旧对象仍可原位编辑；交互边界须明确touch。检查点不能被当成可导入“已批准”文件，持有者也不证明各来源一致。未来费用接入必须先经既有严格快照/事务校验，冻结整个来源、金额、政策及历史，再准备所有关联字段和控制代次；不能直接把任意根补丁当作合格费用。
