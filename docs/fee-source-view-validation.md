# 生产者来源视图独立验证

2026-10-21，第八十七轮。见[设计](fee-source-view-design.md)、[原型](../tools/fee-source-view-prototype.ts)、[普通/失效测试](../tests/fee-source-view.test.ts)和[实际控制器测试](../tests/fee-source-view-state.test.ts)。这些是内部开发证据，不能当作真实贸易、专业复核或正式运行接入验收。

## 本轮做了什么

- 在原开发[夹具](../tools/fee-performance-harness.ts)增加十组明确读取回调；原初始化、总捕获和实际候选准备方法保持。
- 先检查标签闭包、单组与全图原JSON预算，再签发冻结诊断对象；文本共享仍使用上一轮严格codec。
- 私有有效性留在会话和原所有者中；恢复后的JSON没有签发资格。原型无安装、确认、费用应用、文件写入、缓存写入或客户输出方法。
- 1/4/8合成检查记录于[机器可读结果](cases/fee-source-views.json)，含Node/Vite版本、夹具/实现/测试/原控制器的Git blob指纹。运行`npm run check:fee-source-views -- --output benchmark-results/fee-source-views.json`可重现。

## 测试与拒绝边界

新增40项：37项协议/数据/失效检查，加3项实际控制器检查。覆盖十组完整闭包、未知扩展和原型样式键、BOM/CRLF/坏JSON原文、同文不同文件、null/false/空串/不可用状态、冻结与原对象分离；副本/跨会话无资格、原检查点副本无效、A→B→A及嵌套修改后touch失效；读中变更拒绝、读取失败不补null、访问器/toJSON/异步值拒绝、头部和闭包伪造、坏文本引用及跨多生产者的128 MiB展开拒绝。

实际夹具验证：十组投影与各生产者返回值逐项一致；原费用、封套/回执、客户确认和所有者修订保持；未提交输入原文保留；取消封套读取后迟到字节不能产生候选或覆盖当前资料。原总捕获和原预览仍能完成真实十组候选准备；**该测试使用原路径，不把新视图送入运行准备器**。

完整回归为122文件4485项；类型、原领域设计、链接、界面绑定、目录及依赖审计分别执行，远程结果以本轮PR及main实际作业记录为准。既有运行源码、正式格式、Schema、模板、依赖锁文件和离线工具保持。第八十四轮46套原生浏览器流程属于同字节工具的历史证据，本轮未重跑；本轮静态介绍页另做file/HTTP/HTTPS及四种模拟宽度核对，不能替代真实手机。

## 合成诊断结果

单位为UTF-8字节，128 MiB = 134217728字节。逻辑视图大小包含所有投影和协议头；编码后大小是同一诊断协议的文本共享wire。

| 合成行数 | 完整逻辑视图JSON | 编码后JSON | 状态 |
|---:|---:|---:|---|
| 1 | 14261654 | 3397969 | 十组诊断数据完整还原，原状态保持 |
| 4 | 85272017 | 20104779 | 十组诊断数据完整还原，原状态保持 |
| 8 | 270331614 | 未执行 | 单组封套投影及全图均超原预算，停止编码/还原 |

8笔的封套投影单独已为202454731字节；未执行项是null，不记成功或零耗时。全部案例费用写入0，没有实际准备/应用入口。检查命令没有计时或峰值内存数据，完整测试与其他任务的机器负载也不作为速度证据。

**这是一份新诊断协议，尚未证明与旧总捕获等价。**它直接接收生产者返回的结构，而旧捕获另外保存转义后的`retained_json`等完整依据。不能据此宣称正式工具支持4笔，也不能把两份不同契约的字节差当生产提速或容量提升。正式运行4/8笔仍维持第八十五轮的受限结论。

历史第八十六轮的[结果](cases/fee-text-sharing.json)对应[当轮源码](https://github.com/codeding-101/COCUDTT/tree/b9cbb1339ef1626bf049a70c78d85ac068093f99)；本轮夹具只新增读取回调，历史指纹不改写成新运行记录。
