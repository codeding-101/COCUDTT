# 客户 PDF 报价说明验收（第十五轮）

## 交付与边界

客户预览区增加“导出客户报价 PDF 草稿”，先检查公开内容，离线生成原生、可检索的 A4 PDF。生成输入仅为 CustomerQuote 公开字段，经 CustomerDocument 再逐项复制；不接受完整项目、内部成本、利润、来源/保险凭证或假设结果。用户主动填写的公开文字仍须自行复核。原币报价保留原始十进制精度，不补造单价、税额、付款承诺或有效期。

沿用 HTML/Excel 的草稿语义、风险与费用提示、保险基线、进口费用与法定纳税/抵扣资格的区别及责任声明。C 类运费终点不会变成风险转移点；PDF 排版不改变基础概念。费用、税额、退税及利润引擎未改；项目格式 0.8、费用规则 1.2、客户说明 1.0 保持。

长条款自动换行分页，续页重复表头和行名；字号不随文本变小，页码包括总页数。超过 120000 字符或 80 页明确失败，既不截断也不下载半成品。客户检查随项目/公开字段修改失效。点击时复制输入及生成日期，再调用保存选择器，等待期间编辑不改变本次文件；忙碌状态拒绝重复导出。取消、生成失败、写入失败及下载回退不改变项目保存状态、草稿或来源确认。不支持字符在打开写入器前退出，原文保留并提示使用 HTML/Excel。

## 字体与工程选择

锁定 pdf-lib 1.17.1 与 @pdf-lib/fontkit 1.1.1。字体资源随单文件打包，无 CDN、字体请求或交易数据上传。源字体来自 [Noto CJK 官方项目](https://github.com/notofonts/noto-cjk)，遵守附带 [OFL 许可](../src/assets/fonts/LICENSE-OFL.txt)，派生字体更名为 COCUDTT Quote Sans SC。来源、SHA-256、覆盖及转换信息见 [provenance.json](../src/assets/fonts/provenance.json)，工具内可查看许可；应用 Apache-2.0 不替代字体 OFL。

资源涵盖 GB2312 及源字体支持的拉丁、标点、全角字符，共 8663 个字符，并非全部中文或 Unicode。emoji、部分生僻字、双向控制符及非法控制字符明确阻断，不悄悄删改。纯文本网址/HTML 标签不产生链接、脚本或附件。

独立渲染曾发现字体子集会缺字，即使文本提取成功也不能交付。最终使用转换后的 TrueType 资源并完整嵌入该资源，关闭生成时再次子集化，普通示例约 1.46 MB；保留 Unicode 映射。字体仅在导出时解压。单文件约 3.4 MB，Vite 有体积告警：为保留 file:// 离线使用而未拆网络加载的字体或库，后续优化必须重新验证渲染、隐私及离线可用性。

复建字体使用 Python + fontTools 4.65.0，运行 `python tools/build-quote-font.py /path/to/NotoSansCJKsc-Regular.otf`。脚本核验固定上游 SHA-256、生成受审查字符集，将 CFF 轮廓转换为二次 TrueType（最大误差 1 字体单位），保留版权、重命名并生成压缩资源及来源记录。日常 npm 构建使用已提交的资源，无须 Python 或联网。

文本资源按仓库 LF 规范保存，复建脚本显式指定 LF。首次远程 CI 的测试/构建通过但交付一致性失败，定位为本机 CRLF 资源被 raw 导入、提交时转 LF 导致产物变化；修正资源及生成脚本后重新检查两个系统，保留严格一致性门槛。

## 验证与限制

- 新增 25 项：PDF 21 项、真实 UI 事件 4 项；完整 37 文件 783 项通过。覆盖公开白名单、解压 PDF 对象隐私探针、元数据/附件/动作/表单排除、精度、异步快照、分页/几何范围、字符与尺寸失败、检查失效、取消/故障/下载及重复点击。
- 新 PDF Edge 流程 17 项全部通过；网络禁用后仍完成导出，读取实际无头浏览器下载文件，隐私探针不进入客户文件；直接保存 API 用内容捕获/故障替身，不冒充实机文件选择器验收。1440/768/390/320 视口（含字体许可展开）无横向溢出，异常 0。此前九套浏览器流程回归通过，共十套。
- pypdf/pdfplumber 独立打开普通 2 页、长条款 4 页及隐私探针 2 页：可检索中文/金额/术语，长条款拼接精确一致，无表单、附件、页面注释、执行动作或内部元数据，文字处于页面范围内。Poppler 渲染普通及长条款共 6 页并逐页查看，字形、金额、续页、页脚清晰且无裁切。独立提取与逐页查看分别进行，前者不能替代后者。
- 类型、静态绑定、单文件构建及当次依赖审计通过（0 漏洞）。远程 Windows/Linux CI 以本轮草稿 PR 最终提交记录为准。

浏览器/渲染记录使用合成数据，不证明真实业务或专业审查完成。真实 iOS Safari/Android Chrome 下载、分享、打印，其他 PDF 阅读器，以及大文档在低内存手机上的耗时仍待验收。首版为中文说明，可容纳支持范围内的英文公开文字；尚无自动双语模板或可编辑 PDF 表单。
