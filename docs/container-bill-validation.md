# 集装箱账单独立模块验收

第三十三轮，2026-10-14。用户授权继续开发和更新main；公开网站不更新。[模型与依据](container-bill-design.md)先于函数实现，本阶段独立API 0.1，不是可导入项目文件。

## 已实现及限制

最多50账单行，每行1–50个稳定箱ID，分别录入箱型、方向、范围、币种及来源；箱数由唯一ID列表长度得到。日历日免费/收费基准、明确两端是否计入、起止事件/日期、0–3660免费天数和1–20个连续边际阶梯。区分免费后收费日起算与含免费日的整个选中期间日起算，不把最后日高费率追溯全部日期。THC起运/目的地及查验仅支持明确每箱固定项，不推定实务计费单位。

逐日/逐阶/逐箱金额以18位定点整数精确乘加，保留原费率文字，输出原币十进制；不套原引擎六位量化，不自动两位舍入/汇兑。免费天数、零费率和零天数分别审计。来源仅为录入文字，结果始终ASSUMPTION_ONLY，不表示真实账单、专业复核或可推荐。

同箱同范围同方向的日期交集保留同类/联合与分开/分开共享日期三类候选，固定同类也列候选；币种/箱型差异不会隐藏候选。保留免费日期交集、不减掉金额、不输出跨行总额。不同范围或类别不证明没有内含重复，合同需另核。

工作日/节假日、小时截点/部分日、豁免暂停、已耗免费期后截取期间、按票/重量/最低收费、storage、SOC例外和整段追溯阶梯均未建模。未知模式/字段、坏日期、缺条件、重复箱ID和坏阶梯整份拒绝；仅返回固定字段路径的错误，不回显私有值。空账单不表示费用完整或零真实成本。
