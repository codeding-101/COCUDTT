# 独立银行费与固定本金资金假设

2026-11-01，第111轮，本地原型。承接[实际报价与付款交接](fee-contract-settlement-design.md)，在同一份标准1.1付款草稿中明确录入银行费和固定本金单利假设，复用原收付、资金引擎及完整交接载体，不改变项目费用、税基或利润。

银行费来源、实际付款方、经济承担方、日期和依据分别录入。已有费用须由原引擎核对当前方案、责任覆盖与是否计入，重复引用拒算；新增费用须明确声明未列入项目，不自动识别重复账单。代付未建模时继续拒算，未知银行费用不补零，各币种分别汇总。

资金假设由用户明确填写本金、成本性质、测算方、年利率、期间与计息基准，不从合同价或TT/L/C/OA推定。未设置、不建模和明确零成本分开；单利算头不算尾，Actual/365 Fixed在闰年也除365。资金结果独立展示，不改变收付净额或贸易利润。

仅明确启用本轮编辑的独立会话可编辑标准1.1；旧默认会话、1.0及1.2至1.5继续只读保全，不静默升级或激活未知扩展。编辑复用原草稿修订、上下文失效与未保存保护，报价变化后明确重绑不缩放价款、银行费或资金输入。

完整外层载体0.1、4 MiB付款文件和64 MiB/256 MiB/16层保护保持。完整文件交付后明确确认才清除待交接，分项导出不代替完整保存。旧档案付款不自动安装，客户导出、费用应用及正式工作台入口仍未开放。

实现见[控制器](../tools/fee-recovery-settlement.ts)、[组合表单](../tools/fee-bank-funding-panel.ts)及[测试](../tests/fee-bank-funding.test.ts)。结果和后续目标见[验收](fee-bank-funding-validation.md)及[阶段计划](development-stages.md)。真实手机、实际单据与专业复核继续后置，全部候选保留本地。
