# 中国进口双汇率：可复现合成演示

2026-10-17，第五十六轮。此例只核对现有程序的固定输入/公式，不代表最新税则、真实报价、原产地资格或专业审查；没有真实单据。中国一般贸易进口、单商品一票，CIF海运，卖方采购成本未知。

## 文件与操作

- [离线演示页面](../china-import-walkthrough.html)：无脚本、外部资源或存储读取，内嵌固定项目的下载链接。与单文件工具放在同目录，可离线阅读。
- [固定项目](cases/china-import-walkthrough.project.json)：基于现有合成模板，另设固定名称/整理时间并将卖方成本留空；不修改原模板。
- [独立手算记录](cases/china-import-walkthrough.expected.json)：基准与三个实验的固定预期，明确合成、未专业复核、无真实单据。
- [自动化对照](../tests/china-import-walkthrough.test.ts)：既有引擎与独立BigInt整数分手算分别核对固定答案，包含错误输入与来源/利润状态。

先保存当前交易和独立资料。在演示页下载JSON，到工具“项目与导出 → 打开项目 JSON”选择它。打开替换当前交易并重置内存付款/客户/假设参数；独立账单/配对保留但须重新核对，不能假装随项目恢复。不要只根据文件名确认内容。

工具应显示参考测算；卖方利润为无法评估，不能把未知成本填成0。打开或加入最近项目不延长报价/汇率/税率有效期；本例申报日期固定2026-09-10。真实业务须换成实际资料，不能为了使提示消失而确认EXAMPLE来源。

## 基准与四组固定答案

货物净价100,000 USD，运费8,000 USD，实际保险费300 USD，CIF报价108,300 USD；报价恰等于三者合计是本例设定，不是通用定价公式。商业7.00、海关7.08 CNY/USD；虚构关税5%、VAT13%、无消费税，VAT按不可抵扣测算。

| 独立实验 | 完税价格 CNY | 关税 CNY | VAT CNY | 买方总支付 CNY | 相对基准增加 CNY |
|---|---:|---:|---:|---:|---:|
| 基准 | 766,764.00 | 38,338.20 | 104,663.29 | 901,101.49 | 0.00 |
| 仅商业汇率7.20 | 766,764.00 | 38,338.20 | 104,663.29 | 922,761.49 | 21,660.00 |
| 仅海关汇率7.18 | 777,594.00 | 38,879.70 | 106,141.58 | 903,121.28 | 2,019.79 |
| 运费9,000且明确重报CIF109,300 USD | 773,844.00 | 38,692.20 | 105,629.71 | 909,421.91 | 8,320.42 |

每次实验先重新打开基准，不能累计前一实验的修改。汇率在高级设置分别定位CONTRACT/CUSTOMS的USD/CNY；运费在费用明细修改“国际海运费”，重报价格还要单独修改报价。只改运费不会自动改合同报价，不可把最后一行当作纯运费单变量实验。

基准公式：`(100000+8000+300)×7.08=766764.00`；关税`766764×5%=38338.20`；VAT`(766764+38338.20)×13%=104663.286→104663.29`；支付`108300×7+38338.20+104663.29=901101.49`。逐税种先舍入到分，商业支付与海关计税分开；VAT不可抵扣，因此两种成本口径相同。中国进口不计中国出口退税抵减。

未列目的港、代理、查验及国内运输等费用，示例总支付不是完整实际落地成本；CIF运费终点不是风险转移点，保费不是保额或保险认证。缺少海关汇率、非正汇率和零数量会阻断；净价尚未确认可保留参考金额但不能作为确定推荐，已知货值整价包含运保费须先拆分。

## 复现命令与交接

开发环境安装锁定依赖后运行：

```sh
node node_modules/vitest/vitest.mjs run tests/china-import-walkthrough.test.ts
node tools/build-import-walkthrough.mjs --check
node tools/check-capability-evidence.mjs
```

需要更新静态页时运行`node tools/build-import-walkthrough.mjs`，再核对差异和独立预期；不能从引擎当前输出反生成“手算答案”。HTML内嵌项目与固定文件原文一致；格式版本0.8保持，整理时间不代表实际业务日期。

检查输入和结果后另存项目、内部HTML/Excel；客户版保持公开字段白名单，不以本合成项目作真实报价发送。独立付款/账单/配对分别保存，最近项目只是本机便利快照。能力边界见[验证矩阵](capability-evidence-matrix.md)，本轮检查记录见[验收](capability-walkthrough-validation.md)。
