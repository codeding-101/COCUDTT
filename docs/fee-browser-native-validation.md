## 原生浏览器证据

[隔离浏览器驱动](../tools/check-fee-browser-native-isolated.mjs)直接导入新模块，没有编解码器源码变换。39场景与10份编码和Node逐项一致；[资源探针](../tools/fee-browser-native-resource-probe.ts)另执行6组：编码/验证阶段×取消/关闭/替换。每组在实际WebCrypto Promise返回边界人为保持未结束，外层取消先完成；随后40次同实例重叠编码/解码都返回BUSY，没有第二份排队加密。释放后槽归空闲，再编码得到原字节。此探针的门控属于测试调度，不证明底层加密被物理终止。

[实际工作台驱动](../tools/check-fee-browser-native-browser.mjs)复用原42个复杂输入和27个运行状态，共69场景；52份可完整捕获结果与原工作台逐字相同，14类不支持JS对象仍拒绝，四个旧JSON反例保持关闭。覆盖未提交DOM控件、初始化、FX保留、读取活动、文件持有者和存储不可用。真实私有观察、ABA以及控制器取消后迟到文件读取各自验证；没有费用应用。

工作台只在专用诊断构建中附加观察桥与原容量追踪；新编解码器本身没有源码变换。基线、正式合成资料和1笔压力三份浏览器编码通过分块通道交给Node原解码器，并按原格式逐字再编码。测试文件选择/保存API为专用替身，不代表真实磁盘文件操作。
