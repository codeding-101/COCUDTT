## 使用路径与隐私

快速开始下方展开“最近项目 · 本机快照”，点击“读取本机列表”。启动和展开都不读取该缓存；缺失时只显示空列表，不创建键。接受完整内部副本后点击加入，最多3份、单份256 KiB、总1 MiB，满额拒绝，不自动替换或淘汰。标题转义并限80个Unicode码点；显示术语、核算币种、加入时间（UTC）与大小。

完整项目可能含采购成本、来源及未知扩展中的敏感资料。已知独立付款、账单/配对、编辑草稿、客户文字与偏好不被收集；未知扩展仍原样保留。缓存只适用于同一浏览器和来源，不是备份或订单档案；必要资料须另存项目JSON。

打开、删除、清空均先准备、核对影响、独立勾选接受，再执行。打开/删除明确显示所选标题、加入时间和标识。打开按原导入管线解析、重算，明确未另存文件；不更新业务日期、税率或来源。打开会重置内存付款计划、客户文字和假设参数；独立账单/配对保留并重新核对，不假装由项目快照恢复。当前资料请先保存。

## 保护与失败行为

- 输入事件立即撤销准备/接受，完整编辑状态在渲染和执行前再次核对；状态包括原始汇率行、独立资料、客户文字、项目读取代次及保存状态。打开其他文件、迟到读取或缓存storage事件使旧控件失效。
- 操作先提交当前数字或客户文字输入。确认框不抢走尚未提交的输入；重新渲染保留键盘确认框焦点。汇率行不完整/重复时阻断捕获，不静默丢行或补零。
- 打开前再次按完整原文读取缓存；新增/删除/清空沿用独立模块的写前租约与写后读回。不是跨标签原子锁或事务，仍可能出现极短时间内的并发竞态。
- 损坏/未来格式保留完整原文，可下载内部缓存目录文件；此文件不能作为单份项目打开。明确接受丢弃后才清理这个键。导出取消/失败保留缓存，下载回退只提示已发起，不宣称已写入文件。
- 列表读取、加入、删除与备份不改当前交易或项目文件保存状态，不取消无关配对读取；只有实际打开走原替换流程。新缓存不进入客户文件、项目JSON、内部计算报告或原恢复备份。
